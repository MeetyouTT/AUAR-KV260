# 本轮 AI 协作摘要

来源：2026-11-02 当前可见对话与本轮工具输出。此文件是摘要，不是完整原始问答导出。

用户在讨论通用 PYNQ Skill 后提出：“怎么做”。助手提出在独立目录实现可运行的离线初版：合同/HWH 检查、PYNQ 驱动与测试骨架、加法/CRC 两例和模拟验证，保留真实 PYNQ 板测为待验。

实现中采用 Python 3.8 标准库，以当前可核对的 PYNQ Overlay、DefaultIP API 作为生成目标；首版范围限制为有明确启动/完成规则的 AXI4-Lite uint32 接口。

自我纠错轨迹：首轮单元测试发现迟到完成未触发超时。断言原文为 `AssertionError: TimeoutError not raised`。助手向用户说明范围仅为新包模拟测试，将超时判断提前到完成判断之前，复测 15 项全部通过。对应真实反例和限制见 case_studies.md。

后续复现与打包结果由 evidence 中实际输出记录；未在此补写历史问答、个人学习体会、PYNQ 上板经历或不存在的模型版本。
