# 可复用工作流

本文件是使用模板，不能作为已执行历史对话。实际提示词、可见回答、人工判断和验证结果另行保存。

## 1. 提取接口合同

提示词模板：

> 请仅依据附带的寄存器表和 HWH，填写 contract_format.md 的合同。逐项给出来源；缺失项标未知，不猜偏移、位宽、读写副作用、启动或完成语义。判断是否落在本工具支持范围，不能用不受支持字段替代缺项。

人工检查：确认实际板卡/IP 版本、时钟和复位条件；确认控制值是完整命令字；确认完成标志在启动时清除；确认参考结果来自算法定义或独立参考。

## 2. 先检查，再生成

执行 `scripts/generate.py`。遇到 HWH 冲突先定位源资料，保存失败信息；缺少元数据时选择补齐元数据或明确以 INCOMPLETE 骨架继续，不能改成 MATCHED。

提示词模板：

> 根据原合同、HWH 和报错，指出具体冲突字段及其来源。分别列出已知、未知、需要实测的条件；保留原失败，给出最小修正，不把静态检查当作板测。

## 3. 验证生成代码

准备与黄金参考独立的模拟 IP，执行生成后的 test_ip.py。检查地址、写入顺序、输出与超时。加入边界值、错参考和不完成/迟到完成等反例。模拟耗时仅作为工具运行信息，不报告 FPGA 加速比。

## 4. 换一个题目复用

使用相同生成器，替换 IP 合同、HWH、向量和模拟模块；保留核心脚本 SHA，记录是否需要修改核心。只有目录迁移时写“换目录复现”，只有更换接口资料时写“换例复用”，只有实际另一板卡执行后才写“跨板验证”。

## 5. 后续板测

按 readme 在已核对的 PYNQ 环境中使用真实 bit/HWH，记录目标板、运行库版本、SHA、输入输出与报告。没有该环境时该层级保持未验证。Skill 的离线生成能力与作品本体板级成果分别陈述。
