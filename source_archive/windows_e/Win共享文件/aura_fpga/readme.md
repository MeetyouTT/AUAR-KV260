## 目前已知与未知

- 用户确认工具使用 2022.2；具体补丁版本仍需记录。
- 前序用户日志显示 PetaLinux 2022.2 已安装且环境可加载；未见后续新卡启动与配套 DPU 推理验收结果。本轮未连接板卡。
- 三人职责保留：A 硬件与 FPGA，B 视觉/身份/唯一运动进程，C 视听选择/语音/UI。身份采用主机先联调、板端目标保留的阶段安排，最终范围待用户选择。
- 官方对照镜像文件名已记录为 `xilinx-kv260-dpu-v2022.2-v3.0.0.img.gz`；最终项目镜像、实际运行时、参考工程、载板 revision、真实引脚和地址仍待验证。
- 设计包没有创建虚假的 RTL、位流或通过日志。文档中的工程目录、模块与寄存器表是待实现规格。

## 先完成的一个结果

在同一套板卡配置中，B 能运行匹配的 DPU 示例，同时通过 A 的访问方式读取自研寄存器中的 IP_ID 和 VERSION。

该结果成立后，再逐步加入 PWM、命令监督、双麦接收与方向计算。
