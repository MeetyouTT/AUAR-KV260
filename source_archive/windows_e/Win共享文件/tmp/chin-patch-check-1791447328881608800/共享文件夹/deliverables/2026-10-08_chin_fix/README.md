# 口部独立动画：下巴边缘修复（2026-10-08）

已复现并修复五套口型的下巴色块错位，开心大口型最明显。`chin_before_after.png` 上排为修复前、下排为修复后；`before_contact.png` 和 `after_contact.png` 包含五档口型开合程度。

## 原因与修复

旧嘴部椭圆覆盖到 y=164，来源帧的下巴／颈部随动作移动，仿射对齐后仍会被贴到静态脸部内，产生缺口、双边和色块。恢复原图透明通道只能保护人物外部透明轮廓，无法保护脸与颈部之间的 RGB 边界；以前“透明轮廓不变”的检查因此不足。

新增统一的局部合成器 `aura/tools/mouth_compositor.py`，嘴部遮罩收至脸内并羽化，下巴 y>=158 及斜向脸颊外侧保持底图像素。中性两套已导出口型在加载时收紧遮罩，开心两套／低落一套在来源帧对齐后使用同一合成器。原素材文件作为来源保留。

口型开合评分原先也取到 y=165，会把粉色颈部算作张嘴；评分区现止于 y=155。五套口型继续随声音插值，零增益回到各自静息底图。

## 验证结果

- 五套共 151 帧，下巴保护区累计改变像素从 15,252 降为 0；各套最大单通道误差原为 132–229，现均为 0。
- 420 种开合／播放增益组合检查通过，完整透明通道保持一致，五套最大开口均保留明显张嘴。
- 完整回归 550 项通过（63.79 秒），新增测试覆盖下巴、脸颊、透明来源及颈部误识别。
- 实际演示已启动于 http://127.0.0.1:8773/，开心／中性／安慰播放、打断、最终收口检查通过。运行源码指纹见 `regression_verification.json`，画面见 `live_happy.png`。

当前默认临时剧本及实时演示通过同一加载器应用修复；已经导出的旧图片、旧视频和旧基础 ZIP 属于历史快照，不会自动变成修复版。2026-10-06 r1 移机基础包需要合并本次下巴修复补丁后再启动。

## 移机补丁

补丁 ZIP 保持 `共享文件夹/aura/` 和 `共享文件夹/deliverables/` 的相对目录。向原基础包解压目录合并本补丁，更新其中的四个运行代码文件，并重启演示窗口。补丁同时带新回归测试、本说明和局部对照图；文件指纹见包内 `chin_patch_manifest.json`。如果目标机器已独立修改同名播放文件，应按本次合成器调用合并这些修改。

保护范围针对现有 464×480、已对齐的五套姿势；以后增加新取景／新姿势时，需重新核对嘴部与下巴位置。这里验证的是边缘稳定性，不代表已实现音素级口型。
