# 玩偶语气自然感改进 & 角色口径清理 技术记录

- 日期：2026-10-07
- 项目：aura（演示台实时对话链路，`deliverables/2026-10-06_xilan_live/`）
- 结论一句话：**音色不动**；本次只改「对话大脑」侧（人设 + 口语规范 + 多轮记忆），并清理历史遗留角色名「小光」。

## 一、背景与目标
用户反馈演示台本地 Qwen TTS（Base 模型 + ICL 音色克隆，音色「柔亮俏皮」/soft_young）**语气不像真人**。
目标：在**不换音色**的前提下让语气更自然；同时把项目里历史遗留的角色名「小光」清理为本项目角色「汐蓝」。

## 二、根因定位（代码级）
1. **对话主机人设几乎为空** —— `aura/tools/dialogue_host_ollama.py` 的 `SYSTEM_PROMPT` 原文仅“你是桌面玩偶的对话大脑”，**没有角色名 / 性格 / 说话习惯** → LLM 只能输出通用客服腔。
2. **没有多轮记忆** —— `build_user_prompt()` 只送 `transcript + 场景字段`，无历史 → 每轮都像初次见面，不会接话。
3. **标点交给 LLM 自由发挥** —— 实测回复出现半角 `,` `!`；Qwen 的韵律跟着标点走，半角停顿更短、更机械。
4. **采样参数不是问题** —— 模型 `generation_config.json` 已是 `do_sample=true, temperature=0.9, top_p=1.0, top_k=50, repetition_penalty=1.05`（官方推荐值），排除“采样太保守导致太平”。

### 3.2 语气自然感改进（`aura/tools/dialogue_host_ollama.py`，**合同 JSON 字段一个不动**）
1. **注入人设**：`SYSTEM_PROMPT` 改为扮演「{name}」（{description}），来源 `board.runtime.character` 单一事实源；
   并加硬性口语约束：全角标点 / 短句（每句≤15 字）/ 允许自然语气词 / `……` 表犹豫 / 禁止复述与书面语 / 通常一两句。
2. **全角标点规范化**：新增 `to_fullwidth_punctuation()`（半角 `,!?;:()` → 全角），在 `normalize_reply()` 内应用。
3. **主机侧多轮记忆**：`serve()` 维护 `history`（保留最近 `HISTORY_MESSAGES = 8` 条），
   `build_response()` / `ollama_chat()` 透传；**WebSocket 协议字段不变**（`board/runtime/dialogue_client/adapter.py` 无需改）。

## 四、验证方式与结果
- `py_compile tools/dialogue_host_ollama.py` → **COMPILE_OK**。
- `python tools/dialogue_host_ollama.py --selftest --backend mock` → **SELFTEST OK**，
  响应含 `reply_text / emotion / avatar_action / visual_claims`，板端 `policy_validator` 不会拒。
- 提示词与标点函数实测：
  - `to_fullwidth_punctuation('你好,我是汐蓝!今天聊点什么?')` → `你好，我是汐蓝！今天聊点什么？`
  - `build_system_prompt(...)` 正确渲染出「汐蓝 / DeepSeek 鲸鱼娘」人设与口语约束。
- ⚠ **重要发现（务必知悉）**：板端 `normalize_text()` 内含 `NFKC`，会把全角标点**降级回半角**：
  - 实测 `normalize_text('你好，我是汐蓝！今天想聊点什么？')` → `'你好,我是汐蓝!今天想聊点什么?'`
  - ⇒ 主机侧转的全角标点**在端到端链路上会被抹掉**（`aura/tools/realtime_dialogue.py:33`、`aura/tools/realtime_stage.py:104`）。
  - ⇒ 若要让全角标点真正喂给 Qwen，需改 `aura/board/runtime/audio/selected_voice.py` 的 `normalize_text()`
    （即 NFKC 之后再把半角标点转回全角）。
    **代价**：`identity.text` 变化 → **4 段 `DEMO_LINES` 缓存与所有历史缓存全部失效，必须重新生成**（GPU 时间）。
    **建议**：先做「半角 vs 全角 同一句合成对比」小实验，确认收益后再付此代价。
