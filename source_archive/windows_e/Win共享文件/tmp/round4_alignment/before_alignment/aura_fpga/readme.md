# AURA FPGA 框架设计包

日期：2026-09-23。适用：AMD 自主选题赛道初级组、KV260、已确认的 Vivado/Vitis 2022.2 工具路线。

这是针对 AURA 的设计与开工框架，不是已经通过综合、上板或比赛验收的工程。原有方案文件保持原样。

## 从哪里读

1. [详细 FPGA 框架](docs/fpga_framework.md)：官方提交要求、系统结构、模块划分、接口、验证、比赛材料映射。
2. [系统完成后的开工步骤](docs/first_steps.md)：从板卡启动到 DPU 与最小自研寄存器同时工作。
3. [平台记录模板](contracts/platform_manifest.json)：先填写系统镜像和参考工程，未知字段保留 null。
4. [提交要求对照表](docs/submission_matrix.csv)：核对官方要求、负责人和证据位置。

## 目前已知与未知

- 用户确认工具使用 2022.2；具体补丁版本仍需记录。
- 系统正在准备，预计近期完成；本次未连接板卡，未验证启动或 DPU。
- 三人职责按 AURA 三十天个人计划：A 硬件与 FPGA，B 视觉/板端身份/唯一运动进程，C 视听选择/语音/UI。
- 系统镜像名称、运行时版本、参考工程、载板 revision、真实引脚和地址尚未确认。
- 设计包没有创建虚假的 RTL、位流或通过日志。文档中的工程目录、模块与寄存器表是待实现规格。

## 先完成的一个结果

在同一套板卡配置中，B 能运行匹配的 DPU 示例，同时通过 A 的访问方式读取自研寄存器中的 IP_ID 和 VERSION。

该结果成立后，再逐步加入 PWM、命令监督、双麦接收与方向计算。
