支持在明确选择的匿名会话中说：

- “请记住，我的项目叫海风。”
- “你记住了什么？”“查看第一条记忆。”
- “把我的项目改成晨光。”
- “忘记我的项目。”或“删除第一条记忆。”
- “清空本次对话记忆。”

通用条目可用“记住：事项是内容”或“记住：事项等于内容”。支持姓名/名字/称呼、项目名称、颜色等常用别名及中文条目编号。当前最多12个明确条目，键最多16字符、值最多64字符；含义不明确时给出用法，不让模型代替数据库宣布成功。普通聊天不会自动写入这些明确条目。

这是当前对话范围的持久记忆，不按人脸/声纹自动归属个人，不跨会话自动读写。原人脸“我是谁”等问句仍走原来的身份查询；需要查看会话称呼时使用“查看记忆/查看第几条”，不把聊天自述变成人脸身份认证。

用户明确操作在输入提交时落库，不等待TTS或完整播放，因此播放失败、打断或重启不会撤销已经执行的更正/遗忘。助手普通回答仍只有匹配完整播放ACK后才能成为已交付历史。记忆操作及其播报保留在历史归档中，但不再作为事实原话注入后续模型上下文。

更正或遗忘会移除相关旧原话与含旧值的历史轮次的在线召回资格；清空会切断当前会话已有全部历史的在线召回。原始档案不自动删除；这是活动记忆管理，不是从历史备份或模型权重中物理擦除。排除标记只存轮次/原因，不额外存被删值。相关性按显式键、别名及可追溯旧值处理，不能宣称任意语义改写都已识别；同一旧轮次若混有其他话题，也会整轮退出召回，不切断原句中的否定或数字。

所有记忆修改递增会话memory_revision。旧生成结果、旧播放ACK及其他连接使用的过期快照不能回写；新上下文一次读取同一SQLite快照内的事实和有效历史。当前对话不使用旧四轮JSON缓存或颜色锚点，避免遗忘后由旧缓存复活。明确事实仍受原2048上下文预算约束，最多选3项相关事实并保留近期对话，作为资料而非指令；未实现抽象摘要、过期策略或任意个人档案。
