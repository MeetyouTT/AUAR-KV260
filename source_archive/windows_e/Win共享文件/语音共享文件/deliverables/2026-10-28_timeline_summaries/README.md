## 已生效的行为

- 按时间轴整理情节和日摘要：会话按日期及约 5 分钟间隔分段，视觉来源保留 boot、相机 epoch、时间及帧范围。
- 摘要采用有效原文摘录和来源 ID，区分用户原话、已完整播放的回复及相机观察。后台不调用语言模型，不增加 GPU 推理或采样频率，也不保存原始相机图像。
- “总结昨天聊了什么”“回顾今天看到了什么”等明确总结请求优先读取缓存；具体主题、部分时段、尚未生成或异常缓存回退到权威记录查询。语音仍独立于视觉。
- 后台默认每 3 秒检查一次，每轮最多处理 8 个范围，每次最多使用 10000 个来源；每范围最多 256 条摘要，对话缓存总量最多 4096 条，保留期限不超过原来源。
- 原文、播放状态、来源依赖或遗忘发生变化时，SQLite 内置触发器同步使缓存失效；写回前再次检查来源版本，阻止旧任务把已删除内容写回来。跨会话视觉派生内容也携带来源版本。
- 保持原有个人档案授权和匿名会话边界。摘要不自动变成姓名、偏好或身份事实；声纹未现场标定，不自动解锁个人长期记忆。
