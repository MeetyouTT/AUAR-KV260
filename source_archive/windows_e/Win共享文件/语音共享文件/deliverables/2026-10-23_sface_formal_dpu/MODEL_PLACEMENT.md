# 当前正式模型位置

| 功能 | 正式模型位置 | 本轮窗口 |
|---|---|---|
| 人体检测 | KV260 DPU：YOLOX-Nano | 约9.96Hz |
| 人脸检测 | KV260 DPU：YuNet INT8 | 约3.56Hz |
| 身份特征提取 | KV260 DPU：SFace INT8 | 约1.74Hz，正式身份路径 |
| 采集、对齐、解码、跟踪、身份库匹配 | KV260 CPU | 与三模型共享不可变源帧/同一DPU owner |
| 语音前端、ASR、27B对话、TTS | 按原Windows业务配置保留 | 本轮未改或重新验收语音模型 |

SFace不再为每次身份请求调用Windows SFace服务；语音仍按Windows方案运行。三个视觉模型复用已加载的同一B4096平台与owner，未重编程PL或修改运动控制。DPU静态资源与任务busy百分比是两类指标，不能把6.28%解释为FPGA只用了6.28%的逻辑资源。
