# CPU线程核分配独立实板观察

2026-10-22，主任务独占UART/板卡，用户允许共三个终端；第二任务审查部署/回退，第三任务本地分析并准备默认关闭的时效观察。使用已修正版本针脚的[候选r2](../2026-10-22_cpu_affinity_candidate_r2/README.md)，28项软件测试与独立实板/14源/迁移源版本核对通过。**120秒重测通过，600秒长测未通过，核分配未常驻，已恢复原配置。**

保持原5ms解释器间隔、同一14份计时/观测源与模型、30ms上限/5ms guard。只有隔离进程的四个明确Python角色设置自身CPU集合：YOLO/YuNet调用与预后处理线程[2,3]、预览/Windows身份准备线程[0,1]。这是待测策略，不代表独占核或已优化；未知后代可能继承创建者mask。

源和配置/旧库不覆盖生产，120秒双模型观察后始终恢复原服务，RuntimeMax300秒/独立360秒回退。启动与窗口末尾两次核对角色日志、PID及线程启动计数、实际`/proc`归属和CPU集合，期间不反复扫描线程。结束独立审计原版本和DPU后端、GUI/Xserver及timer关闭；候选自身恢复日志缺失单列，不能冒充干净恢复。

本次验收分别报告YOLO≥9Hz、YuNet≥2Hz/native真实完成、占用保护与新增USB、CPU及人脸时效。五秒健康快照达到1000ms TTL即列为时效未过，不能将稀疏快照当逐帧分布。成功须同时通过原吞吐/保护和所有采样人脸时效；新保护标准与旧GIL脚本不同，比较时须分别报告。

本次画面、温度和CPU背景没有固定重放，不能宣称严格同输入加速比、根因已证或三模型长期稳定。正式SFace仍Windows/旧库；不启用影子、新登记或运动。首测USB复发后的正常原应用恢复单独记录，不与模型收益混合。

首次120秒在四角色实际核对成功后因新USB匹配告警中止，没有亲和性性能验收；原版恢复后仍有4275条有界窗口告警，并再次不满足YuNet DPU后端审计。正常原音频关闭→原相机重启→原应用重开一次后，短观察匹配告警从至少5000条（截断）→0，CPU93.80%→54.76%，此为环境恢复、不是模型优化收益。恢复后相机441145/GUI441175/Xserver1077，源/配置/偏好保护和独立timer停止通过。

随后同一策略有界重试120秒通过：计数窗口120.74557秒、YOLO9.90512Hz、YuNet2.40174Hz、CPU56.6573%，292次累计native完成、最大23.29590ms、真超限0/新USB0、1次估计预算偏差；25健康快照人脸结果年龄最大544ms、无TTL超期。四角色mask首末验证和自身恢复/CLOSED通过，原相机443808/GUI441175/Xserver1077已恢复，策略未常驻。稀疏快照不等于逐帧时效或真人覆盖验收。

随后同一策略600秒未完成。最后健康打点约305.78秒，随后YuNet总可选占用**31.04715ms**触发原30ms保护并回CPU，程序自动恢复原配置；累计795次DPU完成含这次故障，VART返回status0，不能称模型算错或硬件损坏。故障execute墙钟30.337163ms/调用线程CPU0.835730ms，wait0.081021ms，观察读取合计墙钟0.125520ms/CPU0.128022ms；上下文自愿+3/非自愿+0，guard未超过、waiting_primary0。观察开销全部计入原保护，无法区分Python/GIL/OS/native/硬件等待中的唯一原因。

独立kernel历史核对覆盖候选窗口，匹配USB新增0；因此本次长测失败不能直接归因USB复发。62个已保存健康快照年龄最大806ms、没有TTL超期，但它们不包含全部逐帧时效，不能以此将长稳失败记为成功。长测没有完整600秒的吞吐/CPU窗口结果，不能填写0或沿用短测值；fault snapshot中已回CPU的发布计数也不能当DPU有效产出。计数/快照口径由`assess_results.py`复算。

长测只扩窗121样本/RuntimeMax900/独立1200秒回退，原finalizer AST相同，5ms GIL/模型/源码/核分配/30ms/5ms不变，另一个终端完成独立审查。短测总体通过包含稀疏TTL门槛，早期GIL长测脚本仅吞吐/保护门槛，二者不能直接作同条件通过率或加速比。

最终自动恢复及独立实读通过：原相机449083、GUI441175、Xserver1077；原生产源/单元/模型、Windows正式身份配置与旧库保持，YOLO＋YuNet DPU，影子/producer/埋点/回退timer和XRT统计关闭。核分配与1ms均未常驻。journald在本轮音频恢复附近由215697/NRestarts28变为441138/NRestarts30，未主动重启，原因未定；按最终实读记录，不能宣称全程没有异常服务重启。
