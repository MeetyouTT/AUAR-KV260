# 27B内部短字段延迟优化（2026-10-18）

本轮继续减少正式回答的开口等待。上一版用户新录音约5.293秒开始正式回答，已确认无等待提示且连续自然；这是上一版本的实录，不当作本版验收。

## 变更及范围

原生Ollama结构化生成时，内部字段从 `a_reply_text / b_emotion / c_avatar_action` 缩为 `a / b / c`，仍按台词、表情、动作顺序生成。解码器恢复为原来的 `reply_text / emotion / avatar_action`，板端协议及双路内容保持。仅改内部序列化名称，保留所有台词，不裁剪聊天内容。

27B权重、IQ4_XS、2048上下文、聊天采样参数、复杂题原生思考及768输出预算均保持；OmniVoice16、参考声线、普通闲聊不插等待提示、短回答整段合成保持。板端相机、YOLO、DPU/FPGA和播放程序不作更换。模型数据仍在项目外D盘。
