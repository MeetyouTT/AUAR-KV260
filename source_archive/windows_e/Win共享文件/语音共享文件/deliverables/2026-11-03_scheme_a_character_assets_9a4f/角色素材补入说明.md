# 正式雪妃角色运行素材

本目录收录9a4f正式运行版本的5件固定输入：model.runtime.json、model.source.ems.json、source_profile.json、yuk_0.ems.resx.json和yuk_0.ems/tex-texture.png。原始字节和原元数据完整保留，来源、SHA及大小见manifest.json。配套ARM64渲染库位于src/tools/libaura_yuki.so，其渲染器源码仍在src/native/avatar。

board/release_9a4f.json已将这6项改为包内source；它们的运行目标路径、实际SHA及380项启动绑定保持一致。board/install.sh board会直接从包内取件，其余外置输入按原清单准备。

在工程根运行 python3 -B build/check_character_assets.py --out /tmp/auar_character_check.json。回执路径必须全新且位于包外。可增加 --runtime 指向安装器生成的aura运行根，复核落盘后的素材。脚本检查6件输入、11项正式配对引用、source_profile依赖、纹理PNG块与ARM64库架构，不打开显示设备或执行渲染库。

source_profile中的历史状态保留其原实验语义。本轮实际验证记录另存于report/evidence/character_assets_validation.json；素材归集和离线通过不替代目标KV260的实际显示、动作及帧率验收。
