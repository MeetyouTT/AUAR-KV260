# 时间轴记忆第一版

2026-10-28：**时间轴 v1 已部署并通过本轮自动验收**。语音对话和视觉文字观察可按时间、主题检索；整套长期记忆方案仍有后续阶段。当前权威数据库在 Windows，板卡通过原接口使用新版服务；ARM 测试通过不代表真实数据库已经迁到 PS。

## 已接通的行为

- 对话档案和视觉事件使用统一的来源结构与时间范围查询。用户原话、完整播放后的回复、相机观察分别标记；不因入镜将访客或画面归入个人档案。
- 对话直接读取原权威档案，个人跨会话历史仍需原档案授权，匿名历史只查当前明确会话。原个人事实的 12 项限制、更正/遗忘规则保持。
- 新视觉事件最多保留 **30 天、10000 个事件，先达到上限就清理**；连续相同描述可在最多 5 分钟的短段内合并，保留首末时间、帧号和观察次数。它只证明采样时所见，不证明期间连续不变或某人执行了动作。
- 同 boot 的实时缓存继续为 24 小时/1000 条、20 秒内新鲜；长期时间轴按配置的有线设备查询，可跨 boot。旧版观察不自动回填并延长期限；新事件不保存原图或录音。
- 日期采用 Windows 接收端 UTC，按配置时区 America/Los_Angeles 解释。板卡当前错误的墙钟不作为日期来源；板端单调时间与 boot/epoch/帧引用仍保留。接收时间不冒充精确动作发生时间。
- 支持今天/昨天/前天、上午/下午/晚上、单个公历日期、上周/本周和最近若干天。日期组合不明确时标明需澄清，不擅自改为不限日期。
- 相关片段按当前请求完整预算注入原 27B；2048 上下文保持。片段可能标为局部摘录，资料不足不代表事件没有发生。显式历史问题优先留出检索空间，普通聊天不等待视觉推理。
- 情节/日分组目前按有效来源即时重建，为原文摘录，不增加一次摘要模型推理。长期后台日摘要和更丰富的事件关联尚未实现。

## 更正、删除与回复归属

“清除画面记忆”沿用本次开机范围；“删除昨天的画面记录”“清除所有视觉记忆”新增明确日期或全设备范围。对应事件与短期缓存一起移除，持久版本屏障阻止旧任务写回。含视觉资料的对话回复登记依赖；下次读取档案时校对版本，已失效来源的旧回复和相关接话不能重新参与召回。无法核验来源版本时，这些派生回复也不进入召回。

助手回复仍只有在样本数、PCM 摘要和完整播放 ACK 匹配后才成为“已经说完”的来源。新增 ACK 时间索引；旧档案没有播放时间时明确标为旧轮次时间近似。个人记忆更正/遗忘仍拒绝旧生成和迟到 ACK。

原始对话归档、SQLite 空闲页和私有备份与“可召回资料”有不同生命周期；本版不声称彻底擦除这些副本。时间轴事件删除、派生回复失效与旧事实更正的自动测试均使用合成库。
