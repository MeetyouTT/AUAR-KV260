# 临时声纹与统一身份关联候选

用户提出的渐进登记逻辑可行：先按声音记录 a1、a2，用户明确要求记住自己后，再把称呼、人脸和声纹关联。这样不用先询问每位访客姓名，也保留了不入镜照常语音对话的行为。本交付已经实现候选和软件验证；尚未接入现役 Windows/板端服务，尚未登记真实用户或验证现场识别精度。

## 已实现的行为

- aN 是临时声音簇的显示代号，内部使用不可复用 UUID。默认只保留 24 小时、最多 32 个活动簇；删除/过期清除锚点和观测，不复用旧代号。原始 PCM 不落盘，模板只允许放在生产私有目录。首次锚点不随不确定匹配漂移；声音不足、已知重叠或分数接近时不给确定代号。
- “记住我，我叫小明”启动关联。“记住我”先询问称呼，在同一张脸、120 秒内接收“我叫小明”。普通聊天只提到姓名是线索，不登记；同名不自动合并。
- 一次登记意图先复用原人脸流程：确认称呼、原自然采样/质量检查、真实 COMMITTED 回执。随后自动进入原三段声纹流程，保留原一致性检查及最终“确认保存身份关联”。用户不用再单独发出声纹登记指令。已登记人脸只能用明确确认后的 EXISTING_CONFIRMED 引用复用，不伪造新提交。
- 两部分真实回执齐全后，私有索引才变为 ACTIVE，姓名通过 person UUID 关联原 face/voice store ID、identity ID、模型、版本与模板指纹。任何 PENDING、ACK 或“登记成功”文本都不能激活关联。
- 未标定声纹仍保持原 NOT_CALIBRATED。已 ACTIVE 的记录可以返回 PROVISIONAL_NAME_CANDIDATE：同轮私有 aN 观测至少三次独立采集且原声纹模板仍有效；或复用已有 CPU 编码向量，按原模板阈值/分差匹配并连续获得三次不同采集。后者支持匿名簇到期或板卡重启后重新形成候选。结果明确标注“未标定”，不称确认身份。
- 已标定声纹沿用原阈值/分差及三次独立证据；视觉沿用原 fresh KNOWN 匹配。人脸仅证明画面中的人，不证明他正在发声。模态指向不同人时返回 CONFLICT，不能默默挑选一个。
- 只有明确问“我是谁”等身份问题才朗读候选和确认提示；普通对话保留结构证据，不反复询问姓名。任何候选、姓名识别及关联都不自动授予个人长期记忆读取权，也不把旧匿名聊天自动重归属。
- 每轮 evidence 保留严格 v1 兼容；v2 增加匿名代号，v3 增加关联身份候选。实际 SpeakerTurns 单 CPU worker 和 TimelineConversationStore 接点已用合成数据贯通，传输中没有 PCM、向量、人脸图像或私有文件路径。

## 为什么需要这些边界

单人入镜不能排除画外人、电视声或重放；普通提名也不等于本人登记。此候选用明确意图、同一捕获窗、原人脸采样、三段声纹及原确认降低误绑定，未宣称完成主动说话者识别或活体防伪。短“嗯”“欸”不足以形成可靠声纹时，仍能对话，只保持未知身份。

姓名、声纹和人脸各自有稳定外键，能避免同名误合并。原模板存储与关联索引属于不同节点，不能做到跨节点一次原子提交；取消、掉线、库修订或一方失败会如实保留“人脸已保存、关联未完成”的 PARTIAL 状态，不能擅自删除已提交模板。

匿名清理是逻辑过期删除，不承诺磁盘取证级擦除。代号墓碑与提交审计元数据保留以防复用；活动模板与近期观测有上限。生产侧应把原身份删除/授权撤销同步到关联索引，保持私有备份和访问控制。

## 验证与实际限制

- 69 项专项通过（8.71 秒）：匿名聚类/防漂移/过期/删除、严格 owner/schema、真实回执门槛、原人脸名称状态、一次意图串联原三段声纹、取消/换脸/无脸、未标定候选/冲突、唯一 CPU worker 的 v3 evidence 及原时间轴存储。
- 原连续声画协作与 PCM 生命周期的 55 项兼容通过（9.20 秒）。这两个分组不代表整项目测试总数；早期测试装配失败日志保留。
- 全部使用合成向量、公开测试名字、假 PCM 和隔离 SQLite，没有读取真实私有模板或声音/影像，没有新载模型、开麦、播放、运动、部署或重启服务。正式 A 源文件及其他代理的冻结候选未编辑。

本轮能证明状态机和集成接口的行为；误识别率、漏识别率、多人/远场效果以及现场阈值还需要真人集中标定。实际部署接线和验证要求见 [INTEGRATION.md](INTEGRATION.md)，候选散列见 [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json)。

prepare_evidence_v2.py / prepare_hub_adapter.py 是初始增量脚手架的历史，不要重新运行覆盖已完成 v3 与名称候选的冻结文件；以 candidate/ 和最终 manifest 为准。
