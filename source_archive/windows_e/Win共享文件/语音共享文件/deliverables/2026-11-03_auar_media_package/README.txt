AUAR·雪妃 演示素材包

本套视觉以明亮浅色背景、淡紫字标和深蓝正文为主。实物照片与实机视频尚未提供，对应区域以“素材待补充”保留。

交付内容
1. output/covers：总封面与“实物照片 / 原理讲解 / 实机效果”三个章节封面，均为 3840×2160 PNG；另有四款封面一览。
2. output/poster：A3 竖版海报，297×420 mm PDF，以及 3508×4961 PNG，按 A3 使用约为 300 dpi。
3. output/video：3 秒字标片头，以及 58 秒章节串联占位样片，均为 1920×1080、30 fps、H.264/AAC。
4. source：SVG 排版源文件、片头 HTML 和素材配置；assets：字标、原始参考与原理讲解素材。

样片顺序
00:00-00:03 字标居中。先保持 1 秒，再用 1.6 秒淡出，最后留白 0.4 秒。
00:03-00:05 实物照片章节及图片占位。
00:05-00:06 原理讲解章节。
00:06-00:56 已完成的 50 秒原理讲解，原有女声与字幕保留。
00:56-00:58 实机效果章节及视频画面占位。

待补素材
项目实物照片：用于总封面、第一阶段封面及海报上方图片区。
实机演示视频/截图：用于第三阶段封面及海报下方实机效果区。
source/media-config.json 已预留 actual_photo、actual_demo_still、actual_demo_video 字段。后续素材可放入 assets，按相同位置替换，保持整体框架。

海报内容依据
项目工程交付 readme.md、赛事技术文档 competition_report_review.pdf 与 release_status.md。
海报说明系统组成、板端与主机分工、视觉随动、对话及播放闭环。未采用缺少相同条件说明的性能承诺。

字标
字标透明版使用内置 imagegen 整理，原始附件保留在 assets/wordmark-reference.png。
最终提示词完整保存在 assets/字标整理提示词.txt；可编辑排版使用该透明图片作为图形字标。

源文件
SVG 保留独立文字、线条和图片占位区域，可在支持 SVG 的软件中继续编辑。
导出的 PNG 与 PDF 可直接用于剪辑、展示或打印。当前占位样片供结构审阅，后续补入实拍素材后再生成最终成片。
