Hooks/API
  bind_presentation(stage, recording): after board_business.bind_recording and
    before AvatarRenderWorker creation. Startup-only instance binding.
  attach_presentation(stage): after build_window; binds bridge/worker reads.
  project_presentation(stage,state): after existing project_business_ui.
  save_production_evidence(stage): first operation in save_evidence. None only
    for nonproduction. Board-production never reaches legacy screenshot code.
  close_presentation(stage): cleanup clears the display epoch.

Lifetime
  A single display slot admits only accepted channel events from its original
  owner. Deadline is request's original monotonic requested_at + at most300s;
  repaint cannot extend it. Long active generation/playback keeps internal
  audio/barge/ACK state even if display expires. Only canonical foreground idle,
  no stream/pending/ready/audio_waiting, output idle/unpaused and phase IDLE can
  retire duplicate visual history/log/core reply. ANSWERED capture PCM and text
  then retire; manually recorded, unsubmitted audio is preserved. Request and
  capture IDs/auto-turn state are retained for normal rearm/ACK provenance.

  Store correct/forget/clear methods are wrapped on this instance after normal
  return (transaction already committed). Successful commit_compaction likewise
  invalidates the slot. Failures and uncommitted compaction do not invalidate.
  Invalidation is conservative across the visible presentation, independent of
  which scope was affected; no DB read or fact/name parsing. This can hide the
  current command's visual confirmation but does not cancel/truncate its audio,
  modify its contents, or manufacture an ACK. Original queued start items whose
  requested_at precedes invalidation cannot rebuild a fresh epoch. New request
  owners after invalidation can display normally.

  Worker read reprojects after releasing its condition. Existing owner writes
  replace packet state on the next public refresh. Invalidation never acquires
  worker.condition: the original worker calls public while holding it. GTK
  widget clearing is queued on its own event loop. No reverse job/Store/clock
  mutex acquisition occurs while holding the presentation mutex.

  Production localhost StageBridge never serves user subtitles (metadata state
  and public portrait frame only), so no HTTP cached body can survive expiry.
  Gtk alone shows the bounded current slot. UiServiceClient.read is masked for
  presentation; identity_snapshot/source-validation remains unchanged.

  board_dialogue_jobs.py has one additional finally line, action=None after
  the existing task_done(). It releases the last consumed Plan/PCM from the
  action worker's otherwise idle stack. Its original queue, ACK/cancel/commit
  operations and ordering are unchanged.

Diagnostics
  Board-production manual and close diagnostics write one bounded atomic file:
    <verified private_root>/diagnostics/latest_metadata.json
  Whitelist: schema, fixed privacy flags, TTL, epoch/counts, ui_closed and
  monotonic diagnostic timestamp. No arbitrary state/config/error/owner IDs,
  transcript/reply/log/turns, names, settings, PCM or images. Private canonical
  owner/permissions and non-symlink file checks apply. No window/frame capture
  subprocess is called. Production GTK exception logging retains only the
  exception class. Other render/audio metrics are existing scalar diagnostics.
