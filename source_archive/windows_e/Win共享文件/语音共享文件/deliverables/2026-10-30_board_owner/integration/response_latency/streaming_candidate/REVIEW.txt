New interface: prepare_text(..., chunk_sink=None). None retains the original
buffered audio path and native-rate support. Ordinary Jobs passes its existing
reply_sink when no explicit audio_converter is configured. A declared converter
retains the original buffered bridge path. No implicit resampling is introduced.

Before any streamed sound: validate complete LLM JSON/reply, enforce original
player whole-text <=240 characters, preflight ALL sentence boundaries, require
the new check_prepared_turn_current API, and call Store.generated as before.
One token is then used for each chunk and for the final complete PlaybackPlan.
Every sentence is checked before TTS and after TTS/before sink. Every ordinary
stream event/packet admission rechecks durable authority, including after a
128-event queue backpressure wait. SQL checks run outside the jobs condition.
The local FSM cue generating path is not switched to awaiting-playback checks.

Streaming requires native 24kHz mono PCM16 and the existing <=720000 samples
player limit; model rates changing mid-turn or non24k fail before such a chunk
is delivered. Complete SHA/sample/token receipt is bound only after all chunks;
partial failure clears queued events and cannot commit assistant_played. A
queued network end is not a playback ACK. Already emitted/physically played
audio cannot be retracted after an independent forget/correction/revocation.

Metadata only: board_business.dialogue.latency reports job-worker-origin ASR,
admission, route and speaker-analysis ENQUEUE time, plus preparation context,
LLM RPC, TTS RPC/call counts, first queued PCM and whole worker duration.
speaker_first_audio_measured=false explicitly distinguishes these observations
from a real speaker/sink first-audio measurement. No speech, IDs, PCM, prompt or
source identifiers are copied into timing diagnostics. Failed preparation timing
may remain only in controller.last_prepare_metrics if prepare_text raises before
Jobs collects it; this is an observation limitation, not a playback bypass.

Scope and performance limits: full validated LLM output is still awaited. TTS
requests remain serial; this overlaps playback of sentence1 with later synthesis.
One-sentence responses have little remaining synthesis to overlap. Identity/local
sequence DIALOGUE_ROUTE fallback remains its original buffered path. No real
latency/ASR/speaker/listening/long-run acceptance is claimed by this agent.
