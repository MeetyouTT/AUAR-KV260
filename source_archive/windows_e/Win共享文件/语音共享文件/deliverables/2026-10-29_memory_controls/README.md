## 新增行为

- 事实更正留下有来源的版本记录，区分当前值与已更正的旧值。普通回答继续只使用当前明确事实；明确查询“查看颜色记忆历史”“查看本次对话项目记忆历史”才返回历史。每项最多保留32条版本，当前语音答复列最近两条，长值明确标为摘录。
- 时间是Windows收到记忆输入的时间，按配置时区解释；不是推断出来的实际发生时间。升级仅为当前有效事实建立基线，不从旧归档恢复可能已被遗忘的历史值。
- 忘记一项或清空相应记忆时，其全部版本记录一起清除；查询历史不能重新带回已遗忘的值。
- “删除昨天关于比赛的对话记录”先按日期和文字主题预览范围、轮数与关联影响。60秒内说“确认删除这些对话记录”才执行；可说“取消删除对话记录”。新删除请求会撤销旧预览，过期、换会话、范围改变或相关记忆变化均不能沿用旧确认。
- 默认只处理本次会话；明确个人范围仍需已有个人档案授权。日期无法解释、主题含糊、超过1000轮原文或2000轮关联范围时停止并要求缩小条件，不回退成全部记录。主题采用字面包含匹配，最长16字符，不使用模型猜测删除范围。
- 确认后删除所选整轮用户/回复数据库记录，并移除依赖该来源的明确事实和版本；同步使情节/日摘要失效，拒绝旧生成和迟到播放确认。视觉记录、其他档案和私有备份不在该操作范围内；不声称完成磁盘介质擦除。
- 新回答记录近期对话、明确事实和历史摘要的来源依赖，删除来源后沿依赖链停止召回后续回复。升级前缺少完整依赖的旧回复保守停止后续相关范围的历史召回，原归档仍保留；影响轮数在预览中说明。
- 记忆指令直接使用数据库结果，不调用27B，并跳过不需要的上下文检索。语音合成失败仍保留已经提交的记忆变更，回复状态标为中断；完整播放ACK的原合同保持。
