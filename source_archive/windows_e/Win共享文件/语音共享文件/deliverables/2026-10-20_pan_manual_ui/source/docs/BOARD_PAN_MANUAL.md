# 视觉追踪手动调轴

运行可选入口 `tools/board_avatar_pan.py`，在“视觉追踪 → 转轴调节”中使用左转、右转、停止。普通步长20µs，精细步长5µs；一按一小步，最多2秒，不能通过长按排队连续转动。返回调节窗口或退出界面会请求停止。显示的当前位置是已读回的脉宽，不是测得的角度。

默认左转减小脉宽；若与现场方向相反，可勾选“左右方向互换”。这一开关只作用于当前手动调节，不决定镜像图像的自动跟随符号。到达1400～1600µs已测边界时对应方向禁用；需要更大机械范围时重新确认机构和硬件限值，界面不自动扩展。

调到镜头正前方后，记录界面显示的数值并交给Ubuntu进行中位校准；在得到现场确认前，接口中的临时REFERENCE和历史1500/1430等测试点都不是已标定的机械中位。本入口不启动跟随，也不会在开机时主动发出点动。

部署使用 `python3 tools/package_board_avatar.py --manual-pan` 选择可选入口；打包器包含两个附加界面工具、运动模块、测试和本文档，不打包本机硬件许可配置。目标板需单独创建 `config/pan_manual.local.json`，包含schema_version=1、核验过的boot_id、fdt_sha256和driver_root。当前工程适配的driver_root为 `/home/root/aura-adaptation-20261006/vsrv-source-14da0e60/unpacked`。该目录、CID、原生库/运行时SHA、联合APP/固件、ABI/build和VART准确路径必须通过门槛，否则按钮保持不可用。配置必须来自实板核验，不能填猜测值；新boot不会自动继承旧运动许可。

界面通过独立控制线程持有Native唯一锁；不能同时运行旧台架脚本或另一个运动写入者。停止和100ms独立硬件租约保留，错误ACK会停止并锁定故障，身份采样期间拒绝新点动。正式跟随仍需独立完成中位、图像极性和源时效验收。

2026-10-20现场接入保留voice-barge-in/667b70d586ca的原230项组件，使用独立启动drop-in；共享旧GTK不回灌到板上。后续Windows更新必须保留附加入口和开机HDMI关闭2秒设置，并重新核验实际运行版本。Ubuntu与Windows分别写自己的回执。
