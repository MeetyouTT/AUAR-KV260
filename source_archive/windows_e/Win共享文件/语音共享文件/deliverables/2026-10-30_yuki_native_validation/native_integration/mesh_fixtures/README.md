# 组合网格原引擎对照输入

三个独立小模型与十三组固定参数。没有引用雪妃资产；64×64 RGBA8 棋盘纹理不透明，红色上边和左边用于辨认方向。PsBuild 编译为未压缩 EMS PSB v4，额外资源块已经逐字节核对 float32LE 数据。生成命令为 `python -I ../make_mesh_fixtures.py`。

把此目录映射为 HTTP 路径 `/mesh-fixtures/` 后，可在现有原引擎参考页中使用各 `*-rig.json`。本目录只包含输入和候选预期，未运行浏览器，也没有原引擎截图或等价性结论。

所有模型的图块坐标为 (64,64)，尺寸 64×64。帧内 bp 是沿 X 平移 0.5 倍图块宽度的绝对网格。存在组合器时，第一控制量 p 的三个绝对网格为沿 X 平移 -0.25、0、+0.25；第二控制量 q 的三个网格为沿 Y 平移 -0.25、0、+0.25 的位移网格。每个控制量的范围均为 [-1,1]、neutralIndex=1、meshType=1。

| 用例 rig | 参数 p,q | 当前原生候选预期模型 bounds |
|---|---|---|
| bp-control | 0,0 | [96,64,160,128] |
| abs-neutral-bp-priority | 0,0 | [64,64,128,128] |
| abs-fraction | 0.5,0 | [72,64,136,128] |
| sum-delta-only | 0,1 | [64,80,128,144] |
| sum-fraction | 0.5,0.5 | [72,72,136,136] |
| sum-two-endpoints | 1,1 | [80,80,144,144] |

建议先观察表中六组。bp-control 与 abs-neutral-bp-priority 区分组合器在中性位置是否仍拥有该字段；abs-fraction 检验半区间线性插值；sum-delta-only 与 sum-fraction 区分后续控制器是位移叠加还是第二个绝对曲面。其余用例覆盖负分数、范围两端和越界钳制。精确参数、四角与哈希见 manifest.json。

这些 bounds 是未投影的模型像素坐标，截图位置还取决于参考页视图。比较应固定视图与画布尺寸；先确认六组都有图块，再按同一投影比较相对位移与尺寸。参数设置必须记录引擎读回值，避免将引擎外层变量钳制与组合器范围钳制混为一项。

当前原生候选假设为：先将 p/q 范围归一化并钳制，相邻样本插值，然后按分量相加；所有控制器均落中性整数样本时撤销有效曲面，但不使用冲突 bp。原引擎如有差异，保留截图和参数，先报告差异，再协调生产代码；不能修改夹具预期以伪造通过。
