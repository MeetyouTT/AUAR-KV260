以下为软件首PCM时间，不是外部声学测量，亦不包含用户句尾静音判定等全部等待：

- 首轮12次ABBA自由生成均为单句，未实际拆分首句。出现的时间差包含预热和调度波动，**未将这些差值作为首句优化收益**。
- 补做两路合成形状预热后ABBA，输入、seed42、原模型/声线一致；语音缓存不命中，四次自由生成文字一致。多句样本首PCM中位数 **5.347→3.362秒**，约提前 **1.985秒（37%）**，分为完整首句及后续两段。第二段数据到达未晚于按首段样本数推算的播放结束时间；这是软件连续性估算，仍待真人听音确认。
- 同轮短句样本仍一次TTS，中位数2.686→2.615秒；不主张明确提速。
- 上线后正式ASR/27B/TTS HTTP两次首PCM3.259/2.291秒，后一轮实际使用两段、缓存未命中、ASR94毫秒，保留当前显式持久会话通道。回答文字与前测不同，不能据此声称受控3.527→2.291秒收益。没有发送播放ACK，不是真人听音。
