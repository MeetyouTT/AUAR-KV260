# DeepSeek YuNet全面审查资料

用途：将本目录的完整提示词和源码/过滤故障资料交给DeepSeek，独立审查YuNet偶发30ms占用超限。资料依据UTC2026-10-23最新三模型DPU正式版整理，早期SFace仍Windows的状态已更新。

使用方式：上传`DeepSeek_YuNet审查资料.txt`，并发送“请按文件开头的完整任务提示词，阅读后面的源码与证据，完成独立审查”。如果客户端支持解压读取附件，也可上传`DeepSeek_YuNet审查包.zip`和[完整提示词](给DeepSeek的完整提示词.md)。若模型无法读取ZIP，使用合并TXT；不要假定仅提供本机路径即可让对方访问。

`source_index.json`区分当前实板回读源码、发布PIN固定源码、未经本次实板PIN确认的辅助源码与测试参考。所有包内文件的SHA见`SHA256SUMS.json`。只读代码审查，不执行或部署包内入口。

本包包含16份与现役导出SHA匹配的源码、7份其他发布PIN固定源码、6份明确标注未有本轮实板PIN的辅助源码和7份测试参考；36份Python仅做AST语法核验，没有运行所附业务测试。两条真实故障的时间分段已从端点重算。合并TXT约455KiB，ZIP约130KiB；具体检查结果见`CHECKS.json`。附件内容较长时，先读提示词、故障JSON和调度/runner/指标源码，再继续关联身份及参考测试。

本次只准备本地提示词和审查资料，没有向DeepSeek或其他外部服务发送内容，没有连接板卡、执行新推理或改变生产配置。资料不含模型权重、现场图像/音频、身份特征、数据库、密钥或原始UART。
