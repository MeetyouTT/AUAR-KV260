## 一、结论先行

| 环节 | 实现 | 实测 |
|---|---|---|
| **TTS（说）** | `audio/tts.py` —— Windows SAPI 中文女声（`Microsoft Huihui Desktop`），经 PowerShell 子进程调用，**零第三方依赖** | 12 字 4.14s（含启动 ~0.5s）；纯语音 3.61s → **≈3.3 字/秒** |
| **VAD（切句）** | `audio/vad.py` —— 能量 + 静音滞后，零依赖 | 合成波形（1.2s 正弦）→ **恰好 1 段、1.80s**（含 600ms 静音尾） |
| **ASR（听）** | `audio/asr.py` —— sherpa-onnx 非流式中文 `paraformer-zh-2023-09-14`（223 MB / int8） | 官方样例 **4/4 识别成功**，**0.15~0.23s/句** |
| **闭环** | TTS 写 wav → 重采样 16k → ASR | 识别结果 **"你好我是桌面玩偶小光"**，与原句**字符重合率 100%** |
| **收尾** | TTS 播完 → 发**既有**事件 `AUDIO_PLAYBACK_STOP` | 状态机自己 `SPEAKING*/ACK_NOD/PUZZLED → IDLE`（不再是"点按钮假装播完"） |

## 三、做了什么

1. **`board/runtime/audio/tts.py`**（新增，板端"唯一 TTS"）
   - `SapiTtsBackend`（PowerShell 调 SAPI）/ `ScriptedTtsBackend`（不出声、只计时，可测）；
   - `TtsPlayer`：`speak_async / speak / is_busy / poll / stop`；`poll()` 在"刚播完"时
     发 `AUDIO_PLAYBACK_STOP`（**不新增事件类型**）；
   - 超时保护 + 异常降级（"TTS 挂了也不许把状态机卡在 SPEAKING"）。
2. **`board/runtime/audio/vad.py`**（新增，turn 切分）
   - 能量（RMS）+ 静音滞后；`accept()` 流式吃采样、吐 `speech_start / speech_end`；
   - **候选帧机制**：先攒 `min_speech_ms` 的候选帧（含起始音），攒够才正式进入 utterance。
3. **`board/runtime/audio/asr.py`**（新增，板端"唯一 ASR"）
   - `SherpaOfflineRecognizer`（`from_paraformer`）+ `find_asr_model`（子目录/int8 变体定位）；
   - 依赖可选：未装或模型缺失只抛 `AsrUnavailable`，**模块仍可 import**（与 `kws.py` 同风格）。
4. **`board/runtime/audio/__init__.py`**：按原约定把三个模块导出（docstring 里"后续 A3 加入"改为已加入）。
5. **`tools/verify_audio_chain.py`**（新增验收）：A1 官方样例识别 / A2 合成波形 VAD / A3 TTS→ASR 闭环。
6. **`tools/demo_stage.py` 接入语音**：「🎤 开始说话」按钮 → 麦克风 → VAD → ASR → 文本自动发给 LLM；
   TTS 播完 → `AUDIO_PLAYBACK_STOP`；新增 `--no-tts / --tts-engine / --no-voice` 开关。
7. **`aura/.venv`**（独立虚拟环境）+ `tools/_tmp_make_venv.bat`（ASCII+CRLF 构建脚本）；
   `tools/run_demo_stage.bat` 改指向 `.venv\Scripts\python.exe`。

## 四、关键决策与踩坑

1. **（关键）onnxruntime 版本冲突 → 独立 venv，不动 ComfyUI 环境**：
   `sherpa-onnx 1.13.8` 需要新 ORT，而便携环境是 **ORT 1.17.1** →
   `The requested API version [28] is not available, only API versions [1, 17] are supported`。
   升级共享 ORT 可能影响 ComfyUI 节点，故建 `aura/.venv`（`onnxruntime 1.30.0 / numpy 2.5.3 /
   sherpa-onnx 1.13.8 / sounddevice 0.5.6 / pillow 12.3.0`，共约 60 MB）。**演示台也跑在 venv 里**。
2. **github.com 不通 ≠ 下不了模型**：`api.github.com` 可查 release、`objects.githubusercontent.com`
   可取资产 → 自写 `gh_assets.py`（`/releases/{id}/assets?per_page=100&page=N` 分页 + `Accept: octet-stream`
   自动跟随 302），顺利下到 223 MB 模型。hf-mirror 的 model API 返回 403，故弃用。
3. **踩坑·VAD 丢起始音**：初版在"判定前"就决定是否收帧，导致进入 utterance 前的
   `min_speech_ms`（180ms）被丢掉（"你好"会少半个字）。改为**候选帧缓冲**（攒够再整体入账）。
4. **踩坑（重复踩）·Cline 终端进程模型**：批内多条命令会互相打断、`start /b` 的子进程会被带走 →
   长任务一律 `Start-Process`（脱离）+ 日志轮询；`run_commands` 一次只发一条。
5. **实测语速校准点**：TTS 实测 **≈3.3 字/秒**，而 P0-2 的 `CHARS_PER_SECOND` 写的是 **4.5**（偏快）。
   本轮**不改** P0-2（避免动已验收行为），仅记录为后续校准项。
6. **唤醒词仍缺**：`kws.py` 用 sherpa-onnx（未装模型）→ 演示台用「按麦 = 按键唤醒」替代，
   真机路线待补 KWS 模型。
