## 一、背景与目标

`avatar_action` 是响应协议里早已存在的字段（v2 才接到播放层），但它的取值此前散落在三处、彼此并不一致：

| 位置 | 原取值 | 后果 |
|---|---|---|
| `fsm._route_emotion` | `ack_nod` / `emo_surprised`(别名 surprised) / `emo_puzzled`(别名 puzzled) | 路由本身正确 |
| `mock_adapter.default_response_factory` | `"wave"` | 名单外 → 被**静默忽略**，本地联调看不到任何动作反应 |
| 请求侧 `allowed_avatar_actions` | 无权威来源（测试/示例里写 `idle/wave/nod`） | 白名单与实际取值不对齐，形同虚设 |

目标（方案 G3「素材清单与实际用例对齐」）：把取值收敛到**一处定义、多处引用**，消除"送了却不生效"的隐患，并为 P1-1 的 `deny_shake` 预埋位置。

## 二、做了什么

1. **新增单一来源** `board/runtime/avatar_actions.py`（纯逻辑，无 Qt、无第三方依赖）
   - `ALLOWED_AVATAR_ACTIONS = (ack_nod, deny_shake, emo_surprised, emo_puzzled)` —— 与方案 §4.1 P0-4 目标集合一一对应；
   - `ACTION_TO_STATE`：动作 → `RuntimeState` 名；`ACTION_ALIASES`：只收历史已识别的 `surprised` / `puzzled`；
   - `DEFAULT_MOCK_ACTION = "ack_nod"`；工具函数 `normalize() / state_for() / is_allowed()`。
2. **fsm 改为引用该模块**（`board/runtime/fsm.py::_route_emotion`）
   - 删掉三行字面量判断；查表命中且 `RuntimeState` 有该成员 → 落该状态；
   - 命中但状态尚未落地（P1-1 之前的 `deny_shake`）→ 忽略，等价于原「未知动作」策略。
3. **mock 改为送白名单内动作**（`board/runtime/dialogue_client/mock_adapter.py`）
   - `avatar_action="wave"` → `avatar_action=avatar_actions.DEFAULT_MOCK_ACTION`（`ack_nod`）。
4. **新增验收脚本** `tools/verify_v2_actions.py`：C1 单点自洽 / C2 fsm 路由 / C3 mock 产出 / C4 素材映射 / C5 burst 语义（仅报告）；按 RESULT 返回退出码。
5. **追加回归单测** `tests/test_fsm.py` 3 个用例：白名单自洽、动作路由、别名与未知动作兜底。

## 三、关键决策与踩坑

1. **行为等价优先**：别名表**只保留** `surprised` / `puzzled` 两种历史写法，不新增 `nod` / `shake`；未知动作仍走 `speaking_state_name(emotion)` 分档兜底 —— 归一化前后 fsm 路由与 v2 **完全等价**（由 C2[unknown] 断言守住）。
2. **白名单先于状态落地**：`deny_shake` 先写入白名单与映射表，`RuntimeState` 成员与素材留给 P1-1。为避免"主机上报了但板端崩"，fsm 用 `RuntimeState.__members__.get(name)` 做存在性判断（**不能**用 `RuntimeState[name]`，后者会 `KeyError`）。
3. **burst 语义不搬家**：`burst / loop` 的单点仍是 `avatar_assets.BURST_STATES`，本模块只提供动作映射，不重复定义，避免出现两处口径。
4. **踩坑·别把"能到 THINKING"当真**：`tests/test_fsm.py::test_full_dialogue_flow` 只断言最终回 `IDLE`，掩盖了链路细节 —— v2 里 `AUDIO_KWS_DETECTED`（自 PRESENT）目标其实是 **AWAKE**，需连发两次 `AUDIO_VAD_END` 才到 THINKING。验收脚本首版按直觉写 `PRESENT→LISTENING→THINKING`，导致 C2 六项全 FAIL；读转换表（`fsm.py:243-258`）后修正为 `PRESENT→AWAKE→LISTENING→THINKING`。
5. **本机无 pytest**（沿用既有事实）：`tests/` 在本机跑不了，因此把"可运行验收"落在 `tools/verify_v2_actions.py`（ComfyUI 便携解释器可跑，只依赖 stdlib + 项目模块），pytest 用例作为留档回归。
