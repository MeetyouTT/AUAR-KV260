一、改的是什么

手段改前改后
入场相位进入状态必从第 0 帧起（相位恒 0）→ 每次说长句都是同一段入场动作进入 loop 状态抽 phase ∈ [0, 1.625s)，每次入场都不同
播放速度恒 1.0 → 循环节恒 = 素材时长 1.625s按回复字数估句长 → speed ∈ [0.85, 1.15]
burst 一次性动作不受影响：不加相位、不变速，仍从第 0 帧起播（AWAKE / ACK_NOD）
