# 实时演示台在本机（D 盘镜像）补齐播放环境 · 技术记录

- 日期：2026-10-07
- 关联交付：`deliverables/2026-10-06_xilan_live`（汐蓝实时演示，浏览器 8773）
- 目的：在本机启动实时演示台试听当前「柔亮俏皮」音色，为音色辨识度盲选提供现场对照

## 1. 背景与目标

交接文档要求播放环境位于共享根 `.venv-live`（Python 3.12 + `aura/requirements-live.txt`）。
本机（D 盘镜像）实际只有 ComfyUI 便携版 Python 3.14.7，且没有 `py` 启动器、没有 `tmp/` 目录，
`run_live_stage.bat` 的三条候选路径（`%AURA_PYTHON%` / 共享根 `.venv-live` / `../tmp/aura-validation-venv`）全部落空 → 无法启动演示台。

## 2. 做了什么

1. 新建共享根 `.venv-live`（官方设计的第一候选路径，`run_live_stage.bat` 会自动选中）
2. 安装 `aura/requirements-live.txt`：PySide6 6.11.2、Pillow 12.3.0、numpy 2.5.3（连带 shiboken6、PySide6_Essentials/Addons）
3. 执行 `realtime_stage.py --check` 前置自检
4. 启动 `realtime_stage.py --root deliverables/2026-10-06_xilan_live` 并实测 HTTP 接口

## 3. 关键细节与技术决策

- **Python 版本**：交接文档写的是 3.12，本机没有；实测 ComfyUI 的 3.14.7 可用 —— PySide6 发布的是
  `cp310-abi3` 稳定 ABI wheel、Pillow/numpy 有 `cp314` wheel，`pip --dry-run` 已验证可解，因此不再额外安装 Python 3.12。
- **不改既有交付**：`.venv-live` 建在共享根（启动器原生候选路径），**没有**改动 `deliverables/2026-10-06_xilan_live/`
  内任何文件，避免破坏该移机包的 `package_manifest.json` 文件指纹。
- **长任务脱离终端**：pip 下载约 160MB，用 `Start-Process` 脱离终端后台执行并写日志轮询，避免被后续前台命令掐断。
- **进程拓扑**：venv 的 `pythonw.exe` 是 redirector，会再拉起一个解释器进程 → **同一实例会出现两个 pythonw 进程**，
  这不是重复启动，**不要**按“去重”杀掉其中一个（本次曾误杀导致服务停止，已重启恢复）。
- **无模型时的行为**：`--check` 报 `inference_model_loaded: false`；四段缓存全部 `cache_hit: true` 可直接播放；
  未缓存的新台词会**明确报错**，不会静默替换成系统音色。

## 4. 验证方式与结果
