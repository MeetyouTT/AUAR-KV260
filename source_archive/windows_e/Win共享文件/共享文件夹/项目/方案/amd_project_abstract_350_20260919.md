# 雾镜 Lite：AMD 赛道项目简介

建议题目：基于 AMD KV260 的视听融合与板端身份识别交互终端

## 报名简介

雾镜 Lite 是基于 AMD KV260 的桌面视听交互终端，拟实现人物检测、单轴跟随、声音辅助选人、板端认人记忆、语音对话与看图问答。采用轻量 YOLO 检测人体，结合 ByteTrack 两阶段关联和借鉴 BoT-SORT 的相机运动补偿，提高遮挡与转头场景下的跟踪连续性；双 I2S 麦克风通过时差估计、短窗互相关和质量判决提供粗声源方向。板端由 DPU 加速视觉网络，ARM 完成跟踪融合、人脸对齐、身份匹配与本地身份库管理，自研 FPGA 逻辑承担同步采样、相关计算、命令时效检查、限速和 PWM 输出。系统经局域网与主机协同完成语音识别、图文理解及语音合成，通过屏幕表情、字幕、语音和实体转动呈现交互。项目重点研究多人及延迟条件下的稳定选人与动作许可，结合按需认人、拒判和异常降级，通过消融实验、软硬件对照及并发实测验证效果。
