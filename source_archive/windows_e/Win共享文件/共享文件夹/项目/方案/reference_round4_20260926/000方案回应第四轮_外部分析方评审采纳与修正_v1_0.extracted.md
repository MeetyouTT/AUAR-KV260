### ③ 麦克风是否随相机旋转，比"单板还是双板"更重要

若麦固定而相机旋转：必须给出相机朝向、坐标转换、误差与拒判条件，且不得把舵机指令角当作实测轴角；

无可靠角度反馈时，"同体安装 + 停止转动后采样"作为优先验证的简化路线。

落点：D5 W01-08 加口径澄清段；000方案回应第三轮 §3.1 第 3 行与 §3.2 ③ 已改写。

### ④ 双麦时钟"32/33 交替"必须写成准确算法

采纳，且复核你的算例正确：

| 项 | 数值 | 说明 |
| --- | --- | --- |
| 32／33 的含义 | 一个完整 BCLK 周期占用的 100 MHz 时钟数 | 与你的理解一致 |
| 严格 1:1 交替 | 平均 32.5 → 3.076923 MHz → fs ≈ 48,076.9 Hz | 偏高约 0.16%，不合格（不是 48,000 Hz） |
| 目标平均分频比 | 100 / 3.072 = 32.552083… | 与你的算例一致 |
| 我方推荐的重复块 | 192 个 BCLK 周期（＝3 个 I2S 帧）＝ 86×「32」＋106×「33」 | 86×32＋106×33 = 6250；6250/192 = 32.552083… → 块内零累积误差，且 192 = 3 帧（WS 与 BCLK 整除） |
| 必需补充的验证 | ① 频率计/ILA 实测 BCLK 均值与 fs；② 抖动上界（块内均匀化 ≤ 10 ns）；③ WS 与 BCLK 帧相位关系 | 写入 D2 §5.2 与 D5 W06-02／W17-07 |

落点：D2 §5.2 表行与新增说明段、D5 W06-02、D5 W17-07、D1 §12.6 第 1 条、BASELINE_CONVERGENCE（随勾选重生成）、雾镜审查记录 F14 修订注记。

### ⑤ 停止链的两条论证要改

采纳两条：

ILA 与 Pmod：ILA 用于观察片内信号，通常不占用 Pmod；"留给 ILA"只在用作外部触发或引出物理测点时才成立，且 ILA 波形本身可作为验证证据 → Q3 改为"待平台占用确认后再定"。

电容位置与失电：若储能电容位于断电开关下游并与舵机并联，断开电源后仍可能继续供能 → 必须把"电容靠近负载"与"尽快失电"一起设计：产出完整接线图（开关位置 vs 电容位置）并做实际失电时间测试（T11 第三段），不接受仅估算。

另采纳你的精确化要求：第二停止回读必须说明观测对象是开关触点、使能状态还是负载供电；"重复读取同一个控制信号不能证明舵机已经失电或停止"。

落点：000方案回应第三轮 §3.1 第 4／5 行、§3.2 ④／⑤ 已按上述改写；扩展板分析 §13.7 的失电估算保留为设计依据，实测失电时间列为验收项。
