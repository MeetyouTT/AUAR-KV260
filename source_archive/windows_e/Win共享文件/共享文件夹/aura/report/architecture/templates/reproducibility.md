# 从零复现框架

## 当前可以复现的范围

Python 3.8+ 标准库可在原开发仓运行软件联调：

```bash

python3 -s tools/aura_project.py demo
python3 -s tools/aura_host.py
python3 -s -m unittest discover -s tests/framework -v
```
