# AURA 镜像与盘符口径（本机实测）

> 日期：2026-10-06。读者：接手 AI / 开发者。
> 目的：把"**哪份是权威副本、本机是哪份、命令里的盘符怎么写、本机到底能跑什么**"一次写清，
> 避免照抄另一侧会话文档里的 `E:\...` 命令在本机（无 E 盘）直接失败。

## 1. 背景与目标

`aura` 这轮（2026-10-05 ~ 10-06）的改动由**另一侧会话**在 `E:\项目\共享文件夹\aura` 完成，
本机是它的**同步镜像**。两侧文档互相引用时盘符不一致，是当前最容易踩的坑：
例如 `docs\说话素材生成与验收工作流_v3.md` 的命令示例全是 `E:\项目\共享文件夹\...`、
`E:\项目\tmp\aura-validation-venv\Scripts\python.exe`，在本机**一条都跑不起来**。

## 4. 命令改写规则（三条最常见）

1. **路径**：在本机跑时 `E:\项目\共享文件夹\X` → `D:\share、\项目开发\FPGA-amd自主命题赛道\X`；
   交给另一侧跑时反向替换。命令里的路径一律加引号，脚本内用 `-LiteralPath`。
2. **Python 解释器**：本机用镜像内 `.venv\Scripts\python.exe`（可用）；**不要**用
   `E:\项目\tmp\aura-validation-venv\...`（本机不存在）；`python` 是 Store 别名，不可用。
3. **回归测试**：本机 `.venv` 没装 dev 依赖 ⇒ `pytest` 不可跑。选项：a) 用 `tools\run_tests_light.py`
   退化跑；b) 先 `pip install -r requirements-dev.txt` 再 `pytest`（会装 PySide6，体积大）；
   c) 以项目侧验证 venv 的 `509 项` + 交付集合 `验证/pytest.log` 为准。

## 5. 本机能力一览

- **可跑**：`.venv` 下的播放 / 剧本 / 冒烟（`tools\demo_script.py`、`tools\run_demo_script.bat`）、
  ComfyUI 提交与取帧、`py_compile`、Word COM 渲染（`render_docx.ps1`，约 1 分钟/份，期间勿跑其它前台命令）。
- **不可跑**：`git`（无仓库）、`pytest`（未装 dev 依赖）、E: 侧任何脚本。
- **UI 点击**：本机 GUI 无法人工点击 ⇒ 一律 `patch tk.Tk.mainloop` + `widget.invoke()` + 定时读控件。
