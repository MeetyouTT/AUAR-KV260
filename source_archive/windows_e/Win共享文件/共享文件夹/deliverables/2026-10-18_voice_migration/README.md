## 在新目录运行

在目标项目根打开PowerShell，执行：

```powershell
.\start_voice.ps1
```

本机沿用已验证的C盘独立语音Python环境，OmniVoice模型路径由服务脚本相对项目根计算，自动使用E盘模型。若更换电脑或环境路径，执行：

