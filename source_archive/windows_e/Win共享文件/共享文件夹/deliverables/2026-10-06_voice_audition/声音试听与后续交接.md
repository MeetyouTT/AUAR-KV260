## 当前选择思路

- **Vivian**：本轮重点。在固定预设声线的基础上，增加开朗游戏少女的语气指令，覆盖问候、解释、兴奋、安慰四种场景。
- **Serena**：温柔、亲近的对照，用于判断用户更喜欢清亮还是柔和。
- **Kokoro zf_001 / sid 3**：现有模型的中文女声对照。四段只改变语速，不能据此宣称它具有独立的情绪控制。

三款使用相同台词，台词和指令见 `audition_plan.json`。Vivian 的四段指令均强调同一个角色，清亮、轻盈、俏皮、清晰；解释长句时保持舒服的节奏，安慰时收敛情绪。描述是生成目标，是否达成仍由试听判断。

## 使用方式

在本机打开 <http://127.0.0.1:8768/>。页面提供每款声音的四段按钮及完整试听，切换声音会暂停前一款。

移到其他电脑后，安装 Python 3，用本目录的“启动试听.cmd”启动页面，随后打开上述地址。单纯试听只需要 Python 标准库，**不需要安装语音模型**。直接双击 HTML 文件会受到浏览器读取本地比较数据的限制。

可以直接播放 `audio` 下的 WAV 文件。`raw` 和 `raw_local` 保留生成原件；`audio` 是近似对齐听感音量的比较版。没有变调、变速或改变角色音色；Kokoro 的速度参数在合成时设置。

页面中“四段试听已齐备”表示文件齐备；“其余正在准备”表示该声音仍有缺段。实际完整状态及检查结果以 `comparison.json` 和 `audio_verification.json` 为准。

## 如果本轮不满意

先区分两个问题：

1. **声音本身合适，但表达不合适**：继续调整语气、语速、句间停顿及兴奋程度。先只重做问候和长句，避免无目的地生成整批素材。
2. **声音本身不合适**：换固定声线；如果预设都不像目标，用 VoiceDesign 根据角色描述创建候选，再用 Base 保存参考声音并在后续台词中复用。每次独立设计整段可能导致角色身份变化，不能仅靠相同文字描述保证长期一致。

反馈可以直接写“声音太厚”“不够清亮”“太甜”“太尖”“长句太平”或“安慰时不像同一个人”。无需一次给出完整技术参数。若提供一个喜欢的声音参考，先提炼明亮度、厚薄、语调、节奏等特征，再确定新的候选方向。

### 备用的新声线设计描述

下面用于下一轮 VoiceDesign 的候选描述，**本轮尚未使用 VoiceDesign 生成**：

> 中文普通话女性声音，具有开朗游戏少女的角色感。声线清亮、轻盈，声区中高，音色干净有辨识度，带少量自然的笑意和俏皮感。像熟悉的伙伴面对面聊天，亲切、有精神，吐字清楚，长句也能听起来舒服。保留自然呼吸和句间停顿，音色不要厚重或沙哑，不要尖锐、捏嗓子或刻意拖长尾音，甜度适中。

只先生成问候与解释长句。选中一条满足角色感又耐听的参考后，固定参考声音，再补兴奋与安慰。是否追加此轮，取决于本轮试听反馈。

## 生成与验证记录

环境为 **PC / SIMULATED**，不是板端运行结果。

本轮最终三款各四段、共 12 段齐备，`audio_verification.json` 状态 **PASS**。两款 Qwen 的最终比较均采用本机生成的样例；Vivian 问候 4.00 秒、解释 12.96 秒，分别花费约 6.99 秒及 21.72 秒生成。本机八段非流式生成的 RTF 约 1.61–1.75，说明此配置需要先生成或预缓存，尚不能据此验收实时交互延迟。旧在线样例保留作追溯，不参与最终两款 Qwen 的比较。

- Qwen：官方 `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`，固定版本 `0c0e3051f131929182e2c023b9537f8b1c68adfe`。本机使用 CUDA、bfloat16、SDPA；模型权重放在 `E:\项目\tmp\Qwen3-TTS-12Hz-1.7B-CustomVoice`，两个权重的校验见 `qwen_model_verification.json`。
- 早期官方在线演示生成的 Serena 样例保留于 `raw`，记录见 `qwen_remote_generation.json`。在线服务匿名推理额度用尽后改为本机生成；在线耗时包含队列时间，不可与本机耗时直接比较。
- 本机 Qwen 生成结果及实际语气指令见 `qwen_local_generation.json`，每段记录时长、生成耗时、显存和 SHA256。最终比较优先使用本机样例；准备过程中可展示已有在线样例，来源逐段记录在 `comparison.json`。
- Kokoro 使用项目现有 `kokoro-int8-multi-lang-v1_1`，生成记录见 `kokoro_generation.json`。沿用项目现有 ASCII 路径兼容逻辑，未修改正式 TTS 后端。
- 试听版统一为单声道 24 kHz、16 位 WAV。音量处理采用 20 ms 分块的活跃段 RMS 近似对齐，目标 0.1、峰值上限 0.95，**不是 LUFS 测量**。检查覆盖文件完整性、采样率、非静音、有限数值、峰值及哈希，不等同于发音或自然度通过人工验收。

## 复现脚本

`generate_local_kokoro.py` 使用现有项目模型生成四段；`generate_local_qwen.py --model-path <模型目录>` 使用本机 Qwen 模型生成两款各四段；`build_comparison.py` 整理比较版；`serve_preview.py` 提供只读本地播放页面。

生成脚本可跳过已完成的片段。若修改台词或提示词，应先复制到新的日期／版本交付目录进行新一轮生成，并单独保留上一轮原件及记录。

Qwen 与 Kokoro 的生成环境放在 `E:\项目\tmp` 的独立目录中，避免改变正式项目环境。最终包携带 WAV、页面、提示词和生成记录；临时 Python 环境、下载缓存和多 GB 模型权重不属于可直接搬迁的试听包。

两套环境的完整已安装版本列表分别为 `qwen_environment_packages.txt`、`kokoro_environment_packages.txt`，作为复现记录保留。CUDA 版 PyTorch 来自官方源，下载器校验官方 SHA256 后安装；试听的 WAV 播放没有这些环境依赖。
