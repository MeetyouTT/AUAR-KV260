> **作废声明（2026-10-06，接收端独立审计 §3 + 本机复核）**：v1 报告 `review\drift_report.txt` 的
> `hand_l/hand_r`（0.58–0.78 带实为 y=892–1188 的长发/腿）、`w@0.45`（y≈700 横带含手/围裙/长发）、

**判断（更正后，不宣布通过）**：`length=124` 让**下部外缘/腰下/腿**更稳（0.56/0.51/0.33），
但在**真正的手与躯干区域并不更好、甚至更差**（手 ROI 1.03、含手横带 1.44、胸部 1.39）
⇒ `length` 只解决“跑得通/时长”，**不是漂移的解法**；须叠加姿势约束（E2/E3）。
所有指标只看轮廓外缘或肤色外观，**不得**单独作为判据，必须配合抽帧与接触表视觉确认。
