状态（2026-10-20接续）：独立CPU环境、固定模型及断网真实公开录音推理已通过，6项核心测试+2项VAD测试通过。用户反馈后新增板端可见点击采样窗口，已实际完成4段10秒MCP01录音；前三段登记临时库1身份/1模板，第四段独立匹配0.8571通过原实验0.70门槛。只证明一人同会话单次新录音验证，不是陌生人/跨天标定；尚未接入正式8792身份查询。详见[本轮验证目录](../语音共享文件/deliverables/2026-10-19_speaker_identity/README.md)。早前混音及空录失败保留，不覆盖最新成功结果。

## 实现

- `../语音共享文件/aura/common/speaker_identity.py`：16kHz单声道PCM16 WAV，单段3–20秒；能量与削波检查；本地SpeechBrain ECAPA适配，CPU推理，192维归一化；至少三条录音的一致性检查和均值模板。
- `../语音共享文件/aura/tools/speaker_identity.py`：独立命令行登记、查询。显式登记同意、人员ID、版本检查；拒绝重复PCM。复用IdentityStore最低分与候选差距拒识。默认不选阈值，运行必须显式传入，输出标记未现场标定。
- `../语音共享文件/aura/tests/framework/test_speaker_identity.py`：合成向量的陌生人/空库/冲突拒识、版本冲突、登记一致性、音频格式/时长/静音/削波验证。

声纹库使用独立路径，例如项目外运行目录下的 `speaker-prototype.sqlite3`；不得给现有人脸库写入声纹。人员ID可在明确核对后复用，不能凭同名自动绑定。原型不修改匿名会话与个人记忆。

## 运行入口

在aura目录使用已装好torch、torchaudio、speechbrain的独立Python环境：

```powershell
python tools/speaker_identity.py enroll --model-directory D:/AIModels/speaker-identity/ecapa --database D:/AIModels/speaker-identity/runtime/speaker-prototype.sqlite3 --threshold <待标定值> --margin <待标定值> --consistency <待标定值> --person-id <明确选择的ID> --name <称呼> --consent --expected-revision 0 sample1.wav sample2.wav sample3.wav
python tools/speaker_identity.py query --model-directory D:/AIModels/speaker-identity/ecapa --database D:/AIModels/speaker-identity/runtime/speaker-prototype.sqlite3 --threshold <待标定值> --margin <待标定值> query.wav
```

以上是参数说明，尖括号必须换成实际值。当前适配器已通过manifest自动核对文件指纹并导出模型ID；--model-id可省略，传入则必须匹配。实际路径为 `D:/AIModels/speaker-identity/ecapa`，独立环境为同目录下venv。配置见语音项目 `aura/config/speaker_identity.local.json`，阈值仍为空、正式服务未接入。
