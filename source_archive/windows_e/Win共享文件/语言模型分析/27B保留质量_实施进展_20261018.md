# 保留27B质量的延迟优化：首版进展

用户确认：KV260保留已有YOLO等视觉与执行任务，不新增语音模型或语音模型FPGA加速。ASR、27B和TTS继续在电脑端。

已开始的优化是流式传输与分句流水线，保留当前27B权重、量化、提示词和采样设置。电脑端已增加实验通道；原界面与首字保护播放仍使用原接口。

真实16GB电脑两轮首PCM到达为6.688/4.016秒，均未命中TTS缓存；这不是实际开口时间，也未达到1秒。两轮内容不同，不能当作固定任务加速比。结果说明传输之外的预填充、解码与TTS仍是重点。

优先级：

1. 复用稳定人设/上下文缓存，避免重复预填充；不以删除必要记忆换速度。
2. 流式分句与合成/播放重叠，保留完整内容；不以无意义开场或强行截短回答冒充有效首句。
3. 同声线流式TTS评估与音频设备常驻；保持首字清楚。
4. 同一个27B目标的运行时与投机解码对照；明确量化目标、采样正确性、显存和草稿接受率。
5. 5090 Laptop 24GB实机做联合测试；不套用桌面5090速度。

聊天效果还需要播放确认后的多轮历史、可更正的长期记忆和稳定人设。实验通道在播放归属接入前不替换正式聊天接口，避免接收成功却未播放的文本污染记忆。
