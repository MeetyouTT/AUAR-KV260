### 2. 性能图与原生软件截图

已找到 [性能曲线与原生截图包](../2026-11-02_性能曲线与原生截图_01a19c53/)：

- 11 张性能 PNG，均有同名 SVG：历史 YuNet 耗时、联合视觉频率、图龄、CPU、SFace 质量、CPU/DPU 固定输入、TTS 及两轮交互等。
- 8 张 Vivado/XSim 原生截图：BD、仿真波形、时序、资源和器件布局。
- 配套数据 CSV、计算结果、来源和图注。

本轮实际计数与上述数量一致；图包 ZIP 的 SHA256 与已保存回执一致。现有图可按 [图片索引与图注](../2026-11-02_性能曲线与原生截图_01a19c53/图片索引与图注.txt)选用，不需要为报告重复截图。

使用时保留这些范围：30 分钟视觉曲线来自历史版本，并非当前整机全部业务的长稳；SFace 1000 对为主机 FP32/INT8 模拟输出评测；两条 TTS 和两轮交互的样本量有限；BD 中音频占位模块不能写成实际 PL 语音链。

### 3. FPGA 仿真与报告

## 三、最值得你现在补充的材料

### 1. 拍六类真实照片

| 照片 | 怎么拍 | 报告用途 |
| --- | --- | --- |
| 整机正面 | 同一最终装配，能辨认外形、屏幕和主要外设 | 整机成果与应用场景 |
| 整机斜 45° | 展示结构、底座和安装关系 | 完整性与机械成果 |
| 开发板特写 | 型号和连接位置清楚 | 平台与电路成果 |
| 接线及供电 | 看清 J2、接口器件、供电侧和线缆去向 | 校核连接图，解释接口 |
| 单轴机构 | 舵机、固定、转轴、支架与运动空间 | 机械结构、零点和行程说明 |
| 实际运行屏幕 | 实屏与作品同框；另留界面原始截图 | 软件成果和实际呈现 |

建议同一次装配集中拍摄，保留原图。没有 CAD 时，可先提供带尺寸的手绘结构图和清晰装配照片；图中数字按实物测量填写。

### 2. 找三类 AI 原始聊天

建议优先选记录完整的三类：

1. FPGA 联合工程、寄存器/控制器或运动监督。
2. YuNet/SFace 等模型改写、量化、编译或错误定位。
3. 语音输出、LLM/TTS 资源协调或记忆一致性。

每例保留“你最初怎么问、模型怎么答、哪里失败、后来如何纠正、用什么验证”。导出文本优先，关键截图可补充；保留日期、工具/模型信息、对应文件/版本。已存在的工程复盘可以复用，原问答缺失的部分如实标注。

### 3. 确认最终功能、设备和版本

把最终启用/待验/暂不纳入的功能列清楚；Windows 实际 GPU 和模型以最终机器环境回执为准，现有 Laptop 记录不能移作桌面版结果。

11 月 3 日 [源码取件说明](../2026-11-03_scheme_a_source_picklist_9a4f/00_取件说明.txt)已将 `9a4f06da…` 作为主审来源，并单列 `71431dc7…` 临时思考对照；最终采用哪一组版本仍需在统一发布清单中确认。较早报告中的 ec12 故障等属于各自保存时点，不能据此判断当前设备状态。

应用、相机、控制器、FPGA、Windows、模型和配置要分别登记，再说明共同运行时的组合。

### 4. 补复现中还缺的输入和入口

优先依据现有方案 A 取件表收齐，而不是重新整理一套目录。当前已登记的重点包括：

- 四份外部设置的可公开初始化模板与安装方法。
- 原生库从 C/C++ 源码和构建定义开始的路线，处理旧对象/静态库依赖。
- 参考 DCP/IP、XCLBIN、DTB、模型及资源的固定来源或重建办法。
- 相机与主业务同名异版文件的独立运行根和部署映射。
- 从取得输入到启动、停止、验收的精确命令及实际回执。

模型不必复制到共享材料目录；准备固定取得/校验方法和本机路径配置。需要公开的配置使用模板，保留程序真实期望的安装文件名和字段。

## 四、哪些内容需要后续实测

已有数据足以制作阶段成果表和多张图。只引用历史阶段结果时，可以保留原始条件；报告若声明最终版完整功能、优化收益或实物参数，则需补对应证据。

| 欲在报告中声明的结论 | 最小应有的实际证据 |
| --- | --- |
| 最终整机交互可用 | 同一版本的一轮录音→ASR→回答→实际播放/字幕；过程日志、版本、成功/失败和结束状态 |
| 跟随/停止与恢复正确 | 最终接线、参考与控制条件、实际响应、停止/失源及恢复记录 |
| 真实角度、速度或停点误差 | 实体标定与测量方法、原始视频/读数；PWM 指令范围不直接换算成已验收角度 |
| 真实引脚 PWM 正确 | 示波器/逻辑分析仪记录及工况；与 RTL 仿真分开 |
| 调度或语音优化有收益 | 同设备、输入、任务集和背景负载的基线/优化配对数据；明确冷暖态、起止事件和样本数 |
| 摘要后仍能召回 | 同一合法会话自然到期后的存储状态，以及真实追问和回答 |
| 冷启动或长时间稳定 | 对应最终版本的真实启动/持续运行记录和失败情况 |
| 他人可从零完整复现 | 可取得的全部输入、新环境逐条执行记录、预期输出和未通过项 |

具体重复次数和观测时长应随实验目的确定。本清单不把额外建议实验变成报告成稿的统一硬性门槛，也未在本轮启动设备或模型。
