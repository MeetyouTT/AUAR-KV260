# 9a4f 工程源码包验证记录

本包以正式对话版本 9a4f 为基线。源码输入已在 Ubuntu 上通过四台 XSim 仿真、Vivado 建工程、BD 验证和顶层综合。硬件实现阶段在本包封存时的状态为 RUNNING。完整实现报告及新 BIT/XSA 按后台验证流程另行归档。

| 已验证项目 | 结果 |
|---|---|
| 四台 RTL 仿真 | tb_nominal、tb_wide、tb_pulse_guard、tb_servo 的 xvlog、xelab、xsim 共 12 步返回 0。实际命令与哈希见 evidence/rtl_xsim.json。 |
| Tcl 错误路径 | 缺项、退出码错误、篡改指纹均被拒绝。Vivado 在坏结果下返回 1，未创建工程。 |

| 比赛 Skill | 28 份原文件。15 项单测、73 个 mock 用例通过。 |
| 软件与模型 | 框架 doctor 和合成 demo 通过。8 个原生库从源交叉编译为 AArch64；两份原始 ONNX 已在锁定的 Vitis AI 环境中独立完成量化、评估和编译。 |
| 固件元数据 | 8 段 XRT 元数据回读成功；DTBO 在两种底图上合并成功。原发布 BIT/XSA 配对导出单独记录在 evidence/firmware_reference.json。 |
