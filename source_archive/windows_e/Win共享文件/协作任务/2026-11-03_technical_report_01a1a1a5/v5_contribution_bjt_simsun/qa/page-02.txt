摘要
桌面交互终端需要持续感知用户、组织多模型计算，并使回答、画面和执行动作保持一致。
AUAR 雪妃采用 AMD Kria KV260 与局域网 Windows 主机协同的结构：KV260 的 PS 负责采集、
视觉预后处理、任务调度、音频前端、语音识别及业务状态，PL 集成单核 B4096 DPU 和自研
运动监督逻辑，Windows 主机承担现有 27B 语言模型与 OmniVoice 语音合成，Ubuntu 用于
构建、模型适配及验证。系统通过同源帧标识、可选模型准入、带租约的执行事务、播放确认
和记忆来源管理，处理资源争用与迟到结果。
历史固定输入实验中，YuNet 的 ARM FP32 与 DPU INT8 路径中位耗时分别为 124.02 ms
和 61.41 ms，SFace 分别为 520.86 ms 和 13.56 ms；对照同时改变硬件与精度。公开独立
1000 对人脸测试中，两种精度路径的准确率均为 98.8%。宽版联合平台使用 66,960 个 LUT、
710 个 DSP，已约束路径 WNS 为 0.001 ns。本次在当前板卡上进行 59.988 s 自然业务观察，
CPU 平均占用 79.43%，主检测与 YuNet 完成频率分别约为 9.89 Hz 和 9.85 Hz，主任务超
周期计数无新增；另完成 30 次 ICMP 往返采样与四套 Ubuntu XSim 测试。
项目形成了多模型部署、PS 与 PL 执行监督、语音交付及离线 PYNQ Skill 的可追溯实
现。报告分别说明历史对照、当前运行观察、软件模拟与 RTL 仿真的条件，不将其合并为完
整物理闭环验收。机械标定、声学端到端延迟和统一版本的全功能持续运行仍需独立测量。
关键词：KV260；软硬件协同；多模型推理；执行监督；语音交互；可复现验证
