## 1. 现在的项目究竟是什么

产品仍是单轴桌面交互终端：看到人、选择交互对象、按授权识别身份、小范围朝对象转动、通过MCP01收音播报，并用Windows模型完成中文对话及目标中的当前画面问答。后续还包括声纹、个人长期记忆、全模型编排，以及感知有效期/调度/FPGA监督的研究与比赛交付。

- KV260 PL：DPU推理与自研VSRV/2运动监督/PWM。
- KV260 PS/Linux：相机、预后处理、跟踪、身份库、共享DPU软件调度、运动服务、音频和界面。
- Windows：已运行的ASR、27B对话、TTS及相关音频处理；声纹和长期记忆按用户10月24日更正已有实现。
- Ubuntu：模型适配、源码/固件构建、证据整理与部署支持。

双I2S麦、声源定位、audio_doa_ip、T13/T14已取消；底盘、机械臂、双轴、全模型迁到DPU、通用PYNQ Skill均不是当前必做。HDMI排查按用户要求暂停；动画采用稳定约8fps路线，不能再以旧24fps目标自动判定当前路线失败。原方案的按键半双工已被已有免点击接话和插话能力推进。

## 3. 能支撑上述判断的关键实测

1. **三模型已有真实业务。** 原生r4的`final-window.json`记录180.841秒、YOLO 9.9369Hz、SFace新增46次、新主/可选超限及gap为0。它支持三分钟短窗通过，不支持长期无故障。
2. **身份有定向真人结果。** 10月24日明确正脸106/106 KNOWN、一个未登记者107次0 KNOWN、两人并排21点0单身份绑定；混合姿态首轮86.79%的失败保留。它们不构成人群总体精度或FAR=0。
3. **两小时观察不能包装成三模型满载。** 原记录7200.054秒、YOLO 9.9527Hz、YuNet完成27116次、无新增fault/gap；SFace新增0，且有页面/显示干预。原始JSON明确`three_model_sustained_load=false`、`paired_optimization_gain=false`、`root_cause_cured=false`。
4. **联合固件不是只有文档。** 构建报告WNS 0.001ns、WHS 0.000ns、DRC Error/Critical Warning 0，原平台663条Warning保留；后续同boot恢复记录又给出VSRV/2加载、ID/STOP及44 ACK往返，并有用户看见与停稳反馈。时序余量很小，不保证新增逻辑一定可放入。
5. **最新随动仍未通过。** 最新可见为continuous-v9/face-source-v11，左线实际画面10%、右线80.647%；绿线X11像素54/55点为绿色。当前每次持续越界累计最多3µs、max10µs/s，是小幅诊断模式。旧版用户反馈方向大致对、抽搐减轻，但慢半拍/过冲/过快/边缘漏检；截至本次资料截止，三分钟新测试结果仍待记录。边界可见、ACK或小步输出不等于完整随人验收。
6. **恢复可用不等于长尾根治。** 历史YuNet与SFace有超限、自动恢复和耗尽锁定；10月25日显式恢复有守卫、探测/ACK与READY证据，保留旧故障计数。不能清计数或沿用某个无故障短窗宣称所有问题消失。

## 4. 哪些属于“还没做”，哪些属于“做了但没验完”

**主要待接/待实现的能力：**真实当前图问答、真实视觉说话人与多人自动选人、跨机全模型统一编排、可变感知有效期校准与PL源绝对期限研究实现、三个可执行比赛Skill。它们可能已有接口或局部代码，但没有完整完成证据。

**主要已实现、待调稳/补验的能力：**人脸随动、最终机械装配/标定、视觉身份广覆盖、持续真实对话与噪声、三模型有人持续负载、故障/恢复/回退、最终联合组合冷启动。转轴当前是实物效果问题，不能仅增加软件测试条数就关闭。

**已在Windows做、待成果对齐：**声纹与长期记忆。缺共享回执或本地最新版证据只表示协作与交付可见性缺口，不表示功能没做。

**交付收尾：**实验/论文结果、三个Skill、最终报告、统一发布清单、视频和非作者复现。它们是项目工作，不是功能演示成功后可省略的附件。

## 5. 建议接下来按这条顺序推进

1. **先关闭当前随动诊断问题。** 记录新左线窗口实际结果；按左右各自验证方向、越线响应、持续移动、回区、失跟和停止，再验证真实路径。把图像源丢失、软件目标变化、PWM许可变化与机械动作分别记录，避免只看ACK猜根因。先补最终机构参考与范围，不把1400..1600µs软件范围称机械标定。
2. **立即对齐Windows已有成果并整理最终版本。** 收集已做声纹/长期记忆的真实入口、版本、已有验收结果，纳入发布清单；不安排重复开发。确认当前语音后端，避免沿用早期4B/旧禁用配置。
3. **推进研究与提交证据。** 先统一任务/时钟/测量合同，完成时效评测Skill和可用分析入口，再做同输入/同负载对照及真实编排接线。板卡空档也可做这部分，不能让转轴占满全部剩余时间。
4. **明确完整目标中ASD、VLM和新PL的交付范围。** 这些原目标尚未被取消。若沿用此前“五天”约束，应由团队明确本次交付项与后续项，并据此写报告；本审计不擅自宣告延期或承诺全部能完成，也不重新给出缺证据的总工期。
5. **冻结后做整机验收和复现。** 同一套代码、模型、固件与配置运行三模型有人请求＋连续语音＋界面＋运动，保留全部失败和恢复，再完成最终报告、视频、包核验与非作者复现。HDMI保持暂停状态并列明临时操作，不算已修复。
