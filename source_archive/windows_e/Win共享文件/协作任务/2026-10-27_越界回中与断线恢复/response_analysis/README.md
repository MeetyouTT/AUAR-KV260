# 本次184ACK与背景位移：数字复核

**镜头背景确实产生约7.20px位移，但响应不像连续线性微转。** 26个合格样本、至少81内点，运动前水平变化最大0.023px。按原capture时间对齐；JPEG获取晚于采集76～283ms（中位141ms），不能把下载时刻当动作时刻。27帧采样间隔152～353ms，只能给时间区间。

出程：0.185秒首次提交1419、0.215秒读回宽度1419；1.394秒最近读回1408时背景仅+0.48px，1.722秒已+4.79px，1.900秒约+7.18px。回程：2.671秒首次增大目标；3.791秒最近宽度1416时仍+6.95px，4.034秒/1419才回到+1.24px。以1px作为明确可见阈值，出程相对首变化提交约1.210～1.538秒、回程约1.119～1.363秒；这些是阈值跨越区间，**不是纯软件延迟或机械时延测量**。

同一最近读回1409，出程dx=0.456px、回程dx=6.928px；最终1420不变时画面还到过−2.84px。存在蓄积后变化、方向滞回或后续摆动的迹象，死区、静摩擦、机构负载、内部舵机控制及少量画面扰动尚不能区分。ACK寄存器相邻采样只能包围capture时刻，也不是外部PWM波形或轴角传感器。

r15源码量纲：位置/脸速均为画幅比例和比例每秒。Kp160相当于0.25(µs/s)/px；速度反馈12相当于0.01875µs/px，100px/s最多只加1.875µs/s，近边界还乘包络。10px越界且向外100px/s仍被6µs/s地板支配。现限速20、加速度100、jerk800：理想到20µs/s需0.325秒，首次0.5µs量化阈值下界约156ms，不包含感知/实际机构响应。

7.20/15≈0.48px/µs只是本次非线性行程的割线。仅作量级估算，6～20µs/s约对应2.9～9.6px/s；1420到1400只有20µs，属于约10px级修正预算。速度和负向行程确实保守，但不能把该割线当线性标定，更不能外推未测的大行程。
