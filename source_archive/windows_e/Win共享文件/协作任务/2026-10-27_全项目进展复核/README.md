## 2. Windows 侧这两天补上的关键成果

### 个人记忆已从“已有实现、待对齐”推进到正式入口集成

[个人记忆交付](../../语音共享文件/deliverables/2026-10-26_profile_memory/README.md)和[动画/对话接续](../../语音共享文件/deliverables/2026-10-26_animation_dialogue/README.md)表明：Windows 已升级兼容 r3，板端设置页已有正式入口。支持明确事实的记住、更正、忘记、查看，授权绑定当前设备启动和交互会话；访客和其他档案不能读取个人内容，更正/遗忘使旧来源、生成和 ACK 失效。

303 项 Windows 回归、27 子测试及真实公开 WAV 服务检查是已保存的历史结果，本轮没有重跑。真人选档与持续使用仍待验。档案授权没有自动采用声纹或看见的人脸，不能将“个人记忆已接入”写成“声画身份融合已完成”。

### Windows 合成画面已实际部署为 16fps

[画面交付](../../语音共享文件/deliverables/2026-10-27_windows_portrait/README.md)记录：Windows CPU 合成 423×438 RGB，经 8796 交给板端原有显示通道；板端继续拥有 FSM、PCM 时钟、口型/动作、取消与交互控制。未新增第二个 native sink。

- 最终布局版短窗 15.925fps；后续交互修复部署短窗 15.876fps，帧间隔滚动 P95 中位 69.31ms。
- 实际停止本任务持有的 Windows 画面进程后，UI 保持本地约 8.005fps，随后恢复远端 16fps；有原始结果和变化预览。
- 24fps 的 P95/P99 未通过既定门槛，正式保留 16fps。
- 真实 MCP01 PCM 时钟、硬件静音下口型/画面连续已检查；约 15.525fps 的 SPEAKING 窗口 P95 约 99.57ms，尚不能宣称所有语音负载都稳定满足 16fps。

这些是 native 提交计数及滚动帧间隔结果，不是面板光学帧率。Windows 登录自动启动尚未配置，启动入口仍需随最终部署说明收齐。

### 语音服务的异常处理已有实质修复

[10 月 26 日自动修复交付](../../语音共享文件/deliverables/2026-10-26_system_completion/README.md)补齐了 TTS 请求总期限、半行/无响应/取消故障注入、锁释放与下一轮恢复、Windows 子进程归属，以及 8791/8792/8795 统一就绪核对。后续 8796 画面服务也已纳入现有启动入口。

已有板端网线公开 PCM 的两轮首音频约 4.506/3.915 秒；另一次后续公开测试 PCM 首音频为 6.48 秒。输入与资源条件不同，不能合成固定响应时间或前后提速比例。最新真人实聊及长稳仍待进行。

## 4. 剩余工作分成三类推进

### 已有实现，需要最终组合验收

视觉身份、语音、个人记忆、16fps 动画及 v14 回中分别已有成果，但同一版下持续实聊＋有人身份请求＋画面＋运动的最终并发证据尚缺。建议先固定当前候选和协议，在人在场时验证选档、记忆跨会话、更正/遗忘、首句、插话、取消、连续回中与恢复；保持各项真实失败记录。

可靠性仍有实质未关闭项：历史 DPU 长尾/锁定、USB 相机/音频异常、音频取消尾音、重新插拔的受控恢复、整机冷启及真实回退。HDMI 冷启花屏仍按用户决定暂停；16fps 软件显示通过没有关闭物理冷启问题。10 月 27 日误拔相机后的受控恢复已成功，不等于自动热插拔恢复已验收。

### 仍缺完整能力或研究实现

真实当前图问答、Light-ASD/多人选人、声纹正式身份接入、跨端全模型统一编排、可变有效期校准和 PL 源绝对期限尚无完整完成证据。声纹工具与个人记忆不需要重新从零开发，应复用已有成果补实际接入和验收。

当前 PL 相对租约与软件检查不能独立覆盖最后检查到 COMMIT 之间暂停的源期限竞态；本轮未找到关闭该问题的新 PL 验收。PS 三模型调度也不能写成 PL 通用模型仲裁。若继续该研究主线，需要可信时间/期限合同、实现与仿真/联合构建/故障注入，不能仅修改报告措辞。
