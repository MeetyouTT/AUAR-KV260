## 脉宽与角度的含义

µs是PWM每个周期内高电平持续的微秒数，用于给舵机位置指令，不能直接当角度。现役帧周期20ms，即50Hz。PL在硬件里拒绝1400～1600µs以外的REFERENCE/COMMIT；仅扩大界面范围不能越过这层限制。

ZIP内 `项目/方案/reference_round4_20260926/器件规格确认_麦克风INMP441_舵机DS3230_技术记录_v1_0.extracted.md` §3记录DS3230的180°版本、500～2500µs和1500µs中点。按该资料的标称线性比例：

| 指令 | 标称位置 |
| --- | --- |
| 500µs | 一侧端点，距中点约90° |
| 1500µs | 电气中点 |
| 2500µs | 另一侧端点，距中点约90° |

哪侧对应左/右取决于安装与已确认极性；最终角度以实机标定为准。1400～1600µs只覆盖标称约18°，约为1500µs两侧各9°，不满足用户目标。

## 1420µs不能直接替代完整行程中点

历史1420µs是现场正前方参考，不是已由两端行程测出的电气中点。如果直接以1420±1000µs估算±90°，会得到420～2420µs，其中420已低于资料标称500下限。

正确路线是先确认电气两端和中点，再让机构正前方与该中点对齐，必要时调整舵盘/支架安装角。若机构、线束或具体舵机无法覆盖180°，应如实记录可用角度并调整机构，不能伪造角度映射达到±90°。1500µs在这里是资料标称值，不能未经现场核验自动回中。

## 必须成套修改的内容

1. **PL能力与位宽。** 当前 `visual_servo.sv` 的width/target/reference_width和boundary_width为11位，最高2047；若只把MAX_US改为2500，11位截断会把2500变成452。须同步扩展至少12位、所有写入切片/读回拼接和范围比较，更新构建身份与配对清单，再重新联合实现。
2. **完整脉冲与期限。** MAX_US=2500时，现公式 `ceil(MAX_US/1000)+1` 的最小lease从3ms变为4ms。重新验证首帧、续租、QUIESCE、到期和显式STOP，不直接沿用所有旧脉冲上限断言；保留源时效与所有权保护。
3. **PS驱动与配置。** PhysicalReference、submit、EdgeConfig、手动面板、初始PWM预算/FakeDevice、帧限位和测试夹具都含窄范围约束。统一采用同一个已标定范围/中点/极性合同，旧构建不得悄悄接收宽范围配置。
4. **角速度与位移预算。** 当前软件20µs/s按标称比例约1.8°/s，中点走1000µs需50秒；PL每20ms最多改变4µs，即200µs/s，理想情况下同段仍至少5秒。只扩大位置范围不会自动提高随动速度。后续应把角速度、加速度、jerk和每源位移额度一起换算、标定并验收，不擅自移除时效保护。
5. **实体标定与上线。** 先验证机构/线束可用行程、正前方和两端，记录具体脉宽—角度映射；再在匹配新固件与驱动下分段验证，最后启用±90°软件角度范围。旧台架范围保留为可回退配置，不能把离线500～2500µs能力标成实物两端通过。
