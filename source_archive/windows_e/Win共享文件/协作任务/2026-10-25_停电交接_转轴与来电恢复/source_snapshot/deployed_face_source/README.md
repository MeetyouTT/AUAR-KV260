已证实 v10 的几何不一致：原人脸质量允许保留至少55%框宽，但模板来自原框16%～84%的核心区域。人脸向左仅余55%可见时，核心模板约43%在图像之外，整块 `matchTemplate` 无法表达负模板坐标；因此一个仍满足原可见脸面积约束的真位移会先被 full NCC 拒绝。向右同理。合成固定纹理在两侧剩余55.56%宽时，v10均拒绝，v11恢复原已知位移。此处“真实位移”指合成输入的已知图像平移，不是真人或机械实测。

v11 优先保留原 full NCC。只有旧脸框在原搜索半径内可能触到画面左右边缘，且 full NCC未成功时，才使用原始真实检测锚模板的可见一列两个互不重叠子块。向左用模板右列，向右用左列；两个固定子块都必须纹理标准差≥8、尺寸≥10px、NCC≥0.80，估计出的 x/y 平移必须各在1.5低分辨率像素内一致，且重建原始模板确实跨出相应水平边缘。最终仍走原可见脸质量：至少55%宽、60%高、24px（320×240域）；发布再由原控制器按48px（640×480域）检查。只保留一个子块或两块位移不一致时均拒绝。

回退只从原实锚模板取子块，不把当前图像裁片滚动更新为模板；普通 full NCC和partial都保留同一个template对象与固定offset。因此不会通过重复“追踪→重seed”逐渐改跟遮挡物或背景。新实锚更新仍需原检测服务提供已确认真实单脸，不使用身体、预测或头向。250ms当前像素期限、500ms实脸锚期限、原始图像stamp、count/key约束不变。v10已验证的晚公布miss时序修复及等同key去冗余NCC继承保留。
