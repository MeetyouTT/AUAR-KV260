## 5. 进度判定（本包带来的新事实）

1. **A 线已有真实上板证据**：KV260 官方镜像可启动、ResNet18 分类与性能有日志；DPU 4.1 独立对照工程已在**主机**构建通过（XO→DPU IP→综合→Vitis link→实现→bitstream），routed DCP 可审阅。
2. **但板端未验收**：`DEPLOYMENT_REVIEW.md` 明示新包**未在板卡加载/推理**；`platform_manifest.json` 仍是 `design_only_not_board_verified`。
3. **风险项**：setup WNS 仅 `+0.001 ns`（新增逻辑必须重跑实现核验）、16 个 I/O delay 方向缺口、600 条 Warning（AVAL-318 64 条、REQP-1731 512 条）、`Pblock=0` 无可重配置分区 ⇒ 自研 IP **放置可行性未证明**。
4. **首个工程成果定义**：同一次加载配置下 DPU 有输出**且**自研寄存器可读 `IP_ID`／`VERSION`（见 `aura_fpga\readme.md` 与 `first_steps.md` §4）。
5. **开发入口**：`first_steps.md` §4（最小自研外设，含 `IP_ID`／`ABI_VERSION`／`SCRATCH`／`STATUS`）→ §5（`servo_pwm.sv` → `motion_guard.sv` → 影子字段与 `COMMIT` → 限幅与速率 → 综合实现）→ §6（接机械）；A 线手册 `A01—A14` 与之对应，`A03`（最小共存探针与放置可行性）为紧邻一步。
