## 2 本轮裁定的功能边界（三层拆分，避免误伤）

| 层 | 功能 | 原载体 | 本轮裁定 |
|---|---|---|---|
| ① **声源方向／听声辩位** | PL 自研双麦 DOA（`audio_doa_ip`）、**T13／T14**、《D2 双麦实现计划》 | 2× INMP441 ＋ I2S 4 根（Pmod[3..6]） | **取消**：不采购、不实现、不验收 |
| ② 视听选人（谁在说话就看向谁） | 主机侧音视频融合选人（**T15**、Light-ASD 类） | 主机侧 Python ＋ 相机 | **其音频空间部分随之失效**（一体机不暴露各麦原始同步样本 ⇒ 无法做音频空间定位）；是否保留"单通道 VAD＋视觉"的弱化版，**待一句确认**（不影响本次采购，见 §8） |

### 4.1 存量设备入场判定（以"联想 thinkplus 会议全向麦／会议音箱"类为例）

> 用途：手上已有 USB 会议一体机时，**先判定再决定是否新购**。铭牌与商家话术只能参考，**最终判据仍是 §3 门槛 + §5 关卡**；本节把判定压缩成"3 步 + 6 条命令"。本项目的需求很窄——**只要"USB 有线免驱能同时录放 + 设备内置 AEC"**，不需要阵列精度，所以存量设备通过率通常不低。

**判定树（3 步）**

| 步 | 观察什么 | 结论 |
|---:|---|---|
| 1 | 是否有 **USB 数据口**（USB-A／USB-C 直连机身，而非"只有一个 2.4G 无线接收器／加密狗"） | 否 → **不适合**（不满足 M1：加密狗是私有无线链路，Linux 通常不识别为声卡，最多识别成 HID） |
| 2 | 用 USB 有线时，系统是否**同时**出现"录音设备 + 播放设备"两个音频条目 | 是 → 进第 3 步；**否** → 若必须装厂商软件才出声，按 M2 判"待实测"；**若只能蓝牙 → 不适合**（见下方注意） |
| 3 | 是否 **UAC 免驱**（不装厂商软件即可录放音；若设备有"免驱／class-compliant 模式"开关，拨到免驱） | 是 → **候选合格**，进板端 G1 |

**注意（蓝牙一律不算）**：蓝牙 **A2DP 是单向播放**、**HFP 虽双向但为窄带电话级**且依赖 BlueZ 栈——两者都**不满足"USB 全双工 ＋ 设备内置 AEC"的对话要求**。本项目统一走 **USB 有线**，不用蓝牙；设备若"USB 只是充电、音频只走蓝牙"，即 M1 不通过。

**板端 6 条命令（G1 精简版：跑完这 6 条即可判"适配与否"）**

| # | 命令 | 看什么 |
|---:|---|---|
| 1 | `lsusb` | 有无该设备；**记下 VID:PID**（供 G7 固定标识，联想常见 VID `0x17ef`） |
| 2 | `arecord -l`；`aplay -l` | **输入与输出是否同时列出**——这是 M1 的硬判据 |
| 3 | `cat /proc/asound/card*/stream0` | 声明支持的**采样率／位深／声道**，以及 in／out 是否各有独立端点（双工能力最准的单点证据） |
| 4 | `arecord -D plughw:X,Y -f S16_LE -r 16000 -c 1 -d 10 t.wav` | 16 kHz 是否直接可用；报错则先 `arecord -D plughw:X,Y --dump-hw-params -d 1 /dev/null` 查支持率，再改 48000 录 |
| 5 | `aplay -D plughw:X,Y t.wav`，**同时**跑第 4 条 | **同时录放能否共存**（M3；这是"能不能一边听一边录"的关键） |
| 6 | `ls /dev/snd/by-id`；`udevadm info -q property` | 设备**稳定标识**（M9，禁止写死 `card` 编号） |

**常见"不适配"的三类真实原因与对策**

| 现象 | 真实原因 | 对策 |
|---|---|---|
| 录放都列出，但录音只支持 48 kHz | 会议一体机固定 48 kHz 输入（很常见） | 用 `plughw`／`plug` 插件或 sox/ffmpeg 重采样到 16 kHz 作为 ASR 前处理；实际格式记入 W02-08／W12-06 |
| 插上后看不到声卡条目 | 只识别为 HID／私有设备（加密狗机型，或需厂商软件） | 改 USB 数据线直连机身；仍不行 ⇒ M2 不通过，按 §4 新购 |
| 录放互相打断、噪声明显 | 与相机**抢 USB 带宽**、或共用 Hub；或 USB 供电压降 | 分开 USB 口、改**独立 5 V／2 A 两脚充电器**供电；按 G4 实测峰值与压降 |

**判定通过后**：登记为"**沿用存量设备**"（BOM 记 0 元、无需新购），但仍须完成 **G4—G9**，尤其 **G5 回声抑制**与 **G6 双讲**——**"能录放"不等于"AEC 有效"**，这两关是唯一无法靠型号或说明书替代的实测项。
**判定不通过后**：按 §4 的 **P0 档（≤500 元）**新购，并把本次不通过的具体原因（哪一条 M 不满足）写进采购备注与 W00-06 待决项表。

4. 录音采样率／位宽／声道数是多少？**16 kHz、16 bit、单声道**是否支持？
5. 放音采样率／位宽／声道数是多少？最大音量时**典型与峰值 USB 输入电流**各是多少 mA？
6. 是否支持 **USB 全双工**（一边放音一边录音）？双讲（两人同时说话）时会不会被降噪或 AGC 压掉一方？
7. 拾音半径标称多少米？对 1—3 m 的普通讲话，录音是否清晰？
8. 是否可用**独立 5 V／2 A 充电器**供电（USB 口只供电亦可）？
9. 断电再上电后的默认状态是什么（是否自动开机、是否默认静音）？
10. 桌面尺寸／重量／拾音孔与出音孔位置？静音键是否为物理键？
11. 是否必须安装厂商软件／App 才能录放音？（必须装 = 不满足）
12. 能否提供**官方说明书或规格表 PDF**（用于第 1／3／4／5 条的书面证据）？
