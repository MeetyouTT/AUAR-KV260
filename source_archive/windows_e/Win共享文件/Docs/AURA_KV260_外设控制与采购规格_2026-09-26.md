# AURA：KV260 外设控制与采购规格

日期：2026-09-26。按用户最新要求只说明连接、控制方法和采购规格，不推荐具体商品品牌。本文中的板卡按此前上下文理解为 KV260，电机为用户图片中的 DS3230 三线数字舵机。尚未连接实物；J2 具体针脚需依据载板版本、原理图、连接器方向和最终 FPGA 设计确定。

## 1. 总体结构

```text
KV260 的 Linux 程序
  ├─ USB 主机口 ─ USB 音频一体机：录音输入 + 扬声器输出
  ├─ HDMI/已验证的显示路径 ─ 已购屏幕（另按规格供电）
  └─ AXI 寄存器 ─ 自研 FPGA 运动监督和 PWM ─ J2 Pmod 信号 ─ DS3230 黄色线

独立 6 V 稳压电源正极 ─ 合适的保护/停止电源通路 ─ DS3230 红色线
独立电源负极 ─ DS3230 棕色线
KV260 信号地 ─ 与独立电源负极建立共同参考
```

KV260 标准载板有四个 USB 主机口与 J2 Pmod 2×6 扩展接口，并非完全没有扩展 IO。Pmod 不是插上线后就能自动使用的 GPIO：必须在 FPGA 工程中把 PWM 接到选定外部端口，配置匹配约束和软件访问路径。[AMD 接口表](https://docs.amd.com/r/en-US/ug1089-kv260-starter-kit/Interfaces)。

## 2. 音响与麦克风：USB 音频控制

购买“麦克风、扬声器和音频处理集成在一起的 USB 会议音频设备”，内部已有 USB 音频接口、麦克风采集和扬声器功放。KV260 通过一根 USB 数据线接收录音数据、发送播放数据，不需要 GPIO 控制振膜，不需要再外接功放或 USB 声卡。

选型要求：

| 项目 | 要求 |
|---|---|
| 接口 | 真正的 USB 数据音频，能同时识别录音输入与播放输出；USB 仅供电不符合要求 |
| 驱动 | 标准 USB Audio Class，支持 Linux 通用 USB 音频驱动；基本录放音不依赖 Windows 专用软件 |
| 处理 | 设备内部 AEC 回声消除；降噪可有，但“AI降噪”不能代替 AEC |
| 双向音频 | USB 模式支持同时录放音；实际双讲时真人声音是否保留，需实测 |
| 音频格式 | 厂家提供采样率、位宽、声道信息；程序能取得可转换为 ASR 输入的 PCM |
| 线缆 | KV260 侧接 USB-A 主机口；设备侧按其接口配数据线，不用只能充电的线 |
| 电源 | 提供最大 USB 输入电流；按板卡单口及全部外设预算核算 |
| 固定装配 | 断电恢复/待机唤醒行为明确，按键和拾音孔可操作、无遮挡 |
| 预算 | 音频一体机按 300～500 元；舵机电源和线材另计 |

软件链路是“USB 录音 → KV260 录音程序 → 语音识别/模型服务 → 返回回答音频 → KV260 播放程序 → 同一台 USB 一体机”。所有回复音频送到同一台设备，便于其内部 AEC 使用播放参考。不要把麦克风直接监听回扬声器，也不要把回复改从屏幕扬声器播放后假定一体机仍有完整回声参考。

Linux 中通常由 ALSA 和 snd-usb-audio 提供基础访问；自建系统需启用相应支持。先检查 lsusb、arecord -l、aplay -l，再分别录音、回放和同时录放音。设备编号可能变化，应用应按稳定身份选择输入输出。应用首版可以保持现有方案的按键半双工；硬件全双工不等于对话程序已经实现打断。

USB 每口最大 900 mA，四口合计 2.1 A；Pmod 电源为 3.3 V/100 mA。屏幕按自身要求供电，舵机不能从板卡 USB 或 Pmod 取电。超出 USB 预算时使用有独立供电、不向上游回灌的合规 USB Hub。[AMD 供电预算](https://docs.amd.com/r/en-US/ug1089-kv260-starter-kit/Powering-the-Starter-Kit-and-Power-Budgets)。

## 3. DS3230：控制信号与动力电源分开

附件给出：4.8～6.8 V，5 V 时堵转 2.0 A、6.8 V 时堵转 2.4 A；PWM 脉宽 500～2500 μs，中位 1500 μs；控制频率 50～330 Hz；图示信号高电平 3.3～5 V。表格写 180°，图示还包含 270°版本，实际订单角度需核对。

“数字舵机”描述其内部控制方式，外部仍是三线脉冲接口，不是数字串口总线。舵机内部已有控制器和电机驱动，通常不需要外置 L298N、TB6612 或其他直流电机 H 桥。

| 线 | 功能 | 接法 |
|---|---|---|
| 红色 | 动力正电源 | 独立稳压 6 V 电源正极，经过适当保护与停止电源通路 |
| 棕色 | 地/负极 | 独立电源负极 |
| 黄色 | PWM 控制 | 经确认的 Pmod PWM 信号；按附件 3.3 V 高电平可作为候选，实测确认 |
| KV260 GND | 控制参考 | 与舵机电源负极共地；舵机大电流直接回电源，不通过细 Pmod 地线回流 |

推荐单只舵机选择正规稳压 6 V/5 A 电源留出瞬态余量；5 A 是供电能力，电流由负载决定。输出不得超过附件 6.8 V 上限。不要把 6 V 接到 FPGA 信号针脚，不用面包板和细杜邦线承载舵机功率。

控制首测可用 50 Hz，即每 20 ms 一次脉冲；1500 μs 为中位。先测信号，再在卸载舵盘或轻载条件下从中位附近小范围测试，最终按实物标定角度、方向、限幅和限速。不能首次就扫到 500/2500 μs 端点。停止 PWM 后是否保持、松开或有其他行为需实测；断电也可能使机构失去保持力。

## 4. 需要买什么“板”

### 推荐：Pmod 引出/接口板 + 独立舵机供电

正式项目已经规划自研 PL PWM 和运动监督，直接由 FPGA 输出最符合当前方案。外部所需的是把接口可靠引出与配电的硬件，不一定需要额外单片机控制板。

- **Pmod 引出板/端子转接板：**与 KV260 J2 2×6 连接器的机械规格和实际针脚映射匹配，清楚区分信号、3.3 V 和 GND；不能只凭“Pmod兼容”就盲插。它只负责引线，不会自动产生 PWM。
- **舵机供电/分线接口：**支持三线 PWM 舵机，信号与动力电源分开；红色动力线可由外部 6 V 供电，端子、铜箔、线束按实际电流和保护方案留余量，无向 KV260 回灌的路径。单只舵机也可用合适端子和连接线实现，不必专门买一块功能板。
- **电平缓冲（按需）：**附件接受 3.3～5 V 信号，可先按 3.3 V 逻辑设计；若需要缓冲或升电平，选择适合推挽 PWM 的单向接口电路，供电与上电状态明确，不把 6 V 当信号电平。
- **功率停止通路：**按方案设计适合直流负载电流的开关或负载开关。普通信号转接板不能代替功率控制和保护。

本地框架预算：双 I2S 麦四根信号，PWM/执行使能/停止输入三根，合计七根。通过 GitHub 核对，官方部分 2022.2 参考平台已经把八个 Pmod 信号用于音频收发，必须在最终工程中重新分配，不能让旧模块和新 PWM 争用。[官方参考约束](https://github.com/Xilinx/kria-vitis-platforms/blob/xlnx_rel_v2022.2/kv260/platforms/vivado/kv260_ispMipiRx_vcu_DP/xdc/pin.xdc)。

### 备用：USB 转 PWM 舵机控制板

若暂时只想让舵机转起来，不等 FPGA 接口完成，可选 USB 控制板。购买条件：

- 面向三线 PWM 位置舵机，不是总线舵机/步进电机控制器。
- USB 在 Linux 上可访问，提供公开串口或 USB 协议及示例，可编程设置脉宽，不能只支持 Windows 图形上位机。
- 支持 50 Hz，目标脉宽范围覆盖实测所需范围；设备标称 500～2500 μs，中位 1500 μs。
- 信号输出满足附件 3.3～5 V 要求；舵机电源外接 6 V，与逻辑/USB 供电关系明确，不能回灌 USB。
- 上电默认输出、失联/超时动作可配置或可核验。

这种板会承担 PWM 生成，适合临时联调；若用于最终系统，要重新考虑方案中的自研 PL 运动监督如何仍然控制最终动作。普通 USB-TTL 转接器本身不产生合格舵机 PWM；普通 PCA9685 板的控制端是 I2C，也不是直接接 USB 就能用的板。

## 5. 双麦定位和屏幕的两项注意

会议一体机用于对话，不应默认能输出每只内部麦克风的原始同步数据。保留项目的 PL 双麦方向功能时，仍需两只同型号、共时钟的 I2S 麦克风；一体机内部 AEC 不会替另外两只 I2S 麦自动消除扬声器声音。首版播放时可暂停根据双麦方向选择目标，避免追自己的声音。

HDMI 屏幕可继续用，但当前镜像/位流必须有相应显示路径。官方 2022.2 [平台说明](https://github.com/Xilinx/kria-vitis-platforms/blob/xlnx_rel_v2022.2/kv260/platforms/README)包含多种 DP 平台；若最终只验证 DP 出图，再考虑方向正确的主动 DP→HDMI 转换器。显示屏电源和触控数据线分别按实物规格连接。

## 6. 下单前给商家的规格说明

音频：需要标准 USB 音频输入输出一体设备，ARM64 Linux 基本录放音不依赖专用软件，设备内置 AEC，USB 模式能同时录放音，提供最大输入电流和音频格式，并说明断电恢复行为。

舵机接口：已有 DS3230 三线 PWM 舵机，需要信号与动力电源分离的接线/供电接口，舵机独立 6 V 供电、按堵转电流留余量，信号为 3.3 V PWM，共地且不能把动力电源回灌主板。若购买控制器，则另要求 Linux 可访问的 USB 协议、50 Hz 和可设置脉宽。

最终 J2 针脚表仍需 KV260 载板 revision、J2 朝向/原理图，以及最终工程端口映射；在这些信息缺失时只能提供上述正确拓扑，不能安全地猜“黄色线接第几针”。
