usage: v++ [options] <input file...>

Generic options:
  -h [ --help ]                         Print usage message
  -v [ --version ]                      Print version information
  --config arg                          Config file
  --list_steps                          List valid run steps for a given target

Options allowed in a config file:

  -D [ --define ] arg                   <name=definition> Predefine name as a 
                                        macro with definition. This option is 
                                        passed to the openCL preprocessor.
  -I [ --include ] arg                  Add the directory to the list of 
                                        directories to be searched for header 
                                        files. This option is passed to the 
                                        openCL preprocessor
  -O [ --optimize ] arg (=0)            Optimize level: [0-3,s,quick]; default 
                                        is 0
  -R [ --report_level ] arg (=0)        Report level: [0-2,estimate]; default 
                                        is 0
  -c [ --compile ]                      Run a compile mode
  -f [ --platform ] arg                 Specify a Platform
  -g [ --debug ]                        Generate code for debugging
  -k [ --kernel ] arg                   Specify a kernel to compile or link
  -l [ --link ]                         Run a link mode, generate a XCLBIN file
  -o [ --output ] arg                   Set output file name. Default: a.xclbin
                                        (link, build), a.xo (compile)
  -p [ --package ]                      Run a package mode
  -s [ --save-temps ]                   Do not delete intermediate files
  -t [ --target ] arg                   Specify a compile target: 
                                        [sw_emu|hw_emu|hw]; default is hw
  --board_connection arg                <DIMM_connector:vbnv_of_DIMM_board> 
                                        Specify a DIMM board file for each DIMM
                                        connector slot
  --custom_script arg                   <kernel_name:HLS_script> or 
                                        <data_file_for_Vivado_scripts> Import 
                                        HLS script(s) or a data file containing
                                        paths to customized Vivado run scripts
  --export_script                       Export HLS script(s) or a data file 
                                        containing paths to generated Vivado 
                                        run scripts
  --from_step arg                       Specify a link step name. If 
                                        intermediate results are available, the
                                        link will fast forward and begin 
                                        execution at the named step if 
                                        possible.
  --input_files arg                     Specify input file(s). Input file(s) 
                                        can also be specified positionally 
                                        without using the --input_files option.
  --interactive arg                     [impl] Launch Vivado with underlying 
                                        project loaded
  --kernel_frequency arg                Set a user defined clock frequency in 
                                        MHz for kernel, overriding a default 
                                        value from DSA
  --log_dir arg                         Specify a directory to copy internally 
                                        generated log files to
  --message-rules arg                   Optional input file containing rules 
                                        controlling messaging
  --no_ip_cache                         Turn off IP cache for Vivado Synthesis
  --remote_ip_cache arg                 Specify single writable IP cache 
                                        directory for block-level synthesis 
                                        (assuming file system write 
                                        permission). Takes precedence compared 
                                        to other read-only user IP repository 
                                        directories. Can reduce compile time 
                                        when iterating on hardware generation. 
                                        Value is an absolute path or partial 
                                        path relative to the build directory.
  --report_dir arg                      Specify a directory to copy report 
                                        files to
  --reuse_impl arg                      <implemented DCP> Import an external 
                                        implemented DCP and only run the XCLBIN
                                        packaging
  --temp_dir arg                        Specify a directory to use for 
                                        temporary files and directories
  --to_step arg                         Specify a link step name. The link will
                                        terminate after completing the named 
                                        step.
  --user_board_repo_paths arg           Add existing directory to the list of 
                                        board repositories. Value is an 
                                        absolute path or partial path relative 
                                        to the build directory. First parsed 
                                        value stays at the front of the list. 
                                        The list of board repositories is used 
                                        to find DIMM board files.
  --user_ip_repo_paths arg              Add existing directory to the list of 
                                        IP repositories. Value is an absolute 
                                        path or partial path relative to the 
                                        build directory. First parsed value 
                                        stays at the front of the list, except 
                                        writable IP cache directory has 
                                        precedence. The list of IP repositories
                                        is used to find IP definition files.

[hls] section:
  --hls.clock arg                       <frequency_in_Hz>:<k0>,..,<kn> Specify 
                                        a frequency in Hz at which the listed 
                                        kernel(s) should be compiled by HLS
  --hls.export_mode arg                 <file_type>:<file_path> Set an export 
                                        mode from HLS with the path to an 
                                        exported file. This compiler version 
                                        supports a single file type 'xo'.
  --hls.export_project arg              Specify a directory where a HLS project
                                        set-up script is exported
  --hls.jobs arg                        Set the number of jobs for launching 
                                        HLS runs
  --hls.lsf arg                         Specify a bsub command to submit a job 
                                        to LSF for HLS runs
  --hls.post_tcl arg                    Specify a TCL file containing TCL 
                                        commands for vitis_hls to source after 
                                        csynth_design
  --hls.pre_tcl arg                     Specify a TCL file containing TCL 
                                        commands for vitis_hls to source before
                                        csynth_design

[clock] section:
  --clock.defaultFreqHz arg             Specify a default clock frequency to 
                                        use in Hz
  --clock.defaultId arg                 Specify a default clock reference ID to
                                        use
  --clock.defaultTolerance arg          Specify a default clock tolerance to 
                                        use
  --clock.freqHz arg                    <frequency_in_Hz>:<cu_0>[.<clk_pin_0>][
                                        ,<cu_n>[.<clk_pin_n>]] Specify a clock 
                                        frequency in Hz and a list of 
                                        associated compute unit names and 
                                        optionally their clock pins
  --clock.id arg                        <reference_ID>:<cu_0>[.<clk_pin_0>][,<c
                                        u_n>[.<clk_pin_n>]] Specify a clock 
                                        reference ID and a list of associated 
                                        compute unit names and optionally their
                                        clock pins
  --clock.tolerance arg                 <tolerance>:<cu_0>[.<clk_pin_0>][,<cu_n
                                        >[.<clk_pin_n>]] Specify a clock 
                                        tolerance and a list of associated 
                                        compute unit names and optionally their
                                        clock pins

[connectivity] section:
  --connectivity.nk arg                 <kernel_name:number(:compute_unit_name1
                                        ,compute_unit_name2...)> Set the number
                                        of compute units per kernel name. 
                                        Default is one compute unit per kernel.
                                        Optional compute unit names can be 
                                        specified using a comma delimiter
  --connectivity.noc.connect arg        <compute_unit_name>.<kernel_interface_n
                                        ame>:<noc interface> Manually specifies
                                        connectivity when attaching to Versal 
                                        NoC.  Valid values are internal memory 
                                        controllers, or master interfaces on 
                                        the Versal NoC cell.
  --connectivity.noc.read_bw arg        <compute_unit_name>.<kernel_interface_n
                                        ame>:<Bandwidth in MB/s>.<Avg burst 
                                        length> Manually specifies expected 
                                        read traffic characteristics on axi 
                                        master interfaces to override automatic
                                        Versal NoC configuration.  Specified in
                                        MB/s.
  --connectivity.noc.write_bw arg       <compute_unit_name>.<kernel_interface_n
                                        ame>:<Bandwidth in MB/s>.<Avg burst 
                                        length> Manually specifies expected 
                                        write traffic characteristics on axi 
                                        master interfaces to override automatic
                                        Versal NoC configuration.  Specified in
                                        MB/s.
  --connectivity.sc arg                 <compute_unit_name>.<kernel_interface_n
                                        ame>:<compute_unit_name>.<kernel_interf
                                        ace_name> Specify AXI stream connection
                                        between two compute units
  --connectivity.slr arg                <compute_unit_name>:<SLR_id_string> 
                                        Specify SLR mapping for compute unit
  --connectivity.sp arg                 <compute_unit_name>.<kernel_interface_n
                                        ame>:<sptag> Specify system port 
                                        mapping for compute unit
  --connectivity.spalloc.data_width arg <sptag>:<width> Specify the width, in 
                                        bits, of the memory port associated 
                                        with a given sptag.  Default value of 
                                        64.  Valid values are power-of-two 
                                        sizes from 32 to 1024.
  --connectivity.spalloc.dma arg        <sptag>:<dma sptag> Specifies the 
                                        interface to be used for syncing to the
                                        memory resource associated with a given
                                        sptag.  Default value is determined 
                                        based on existence of DMA interfaces in
                                        the platform.
  --connectivity.spalloc.mem_type arg   <sptag>:<type> Specifies the type of 
                                        the type of the implementing primitive 
                                        associated with a given sptag.  Default
                                        value of BRAM.  Valid values are BRAM 
                                        and URAM.
  --connectivity.spalloc.num_ports arg  <sptag>:<count> Specifies the number of
                                        ports used for the implementing 
                                        primitive associated with a given 
                                        sptag.  Default value of 1.
  --connectivity.spalloc.range arg      <sptag>:<range> Specifies the size in 
                                        bytes of the memory associated with a 
                                        given sptag.  Default value is 8192.  
                                        Values specified with a suffix of "K" 
                                        or "M" are permitted for kilobytes and 
                                        megabytes respectively.
  --connectivity.spalloc.slr arg        <sptag>:<slr> Specifies the SLR that a 
                                        memory resource associated with a given
                                        sptag should be bound to.
  --connectivity.spalloc.sptag arg      <tag> Allocates a memory resource for 
                                        configuration by connectivity.spalloc.*
                                        directives and for use by other 
                                        resources via the connectivity.sp 
                                        directive.

[debug] section:
  --debug.chipscope arg                 <compute_unit_name>[:<interface_name>]>
                                        Enable System ILA IP core insertion 
                                        (interface_name is optional)
  --debug.list_ports                    List valid compute units and ports for 
                                        debug
  --debug.protocol arg                  <compute_unit_name>[:<interface_name>]>
                                        Enable protocol analyzer IP core 
                                        insertion (interface_name is optional)

[drc] section:
  --drc.disable arg                     Disable the Design Rule Check for the 
                                        specified ID. A disabled check is not 
                                        executed.
  --drc.enable arg                      Enable the Design Rule Check for the 
                                        specified ID.
  --drc.severity arg                    Change the severity of a Design Rule 
                                        Check; format <ID>:<severity>[:context]
  --drc.waive arg                       Waive the Design Rule Check for the 
                                        specified ID. A waived check is still 
                                        performed, but marked as waived.

[advanced] section:
  --advanced.misc arg                   Specify advanced tool directives for 
                                        kernel compilation
  --advanced.param arg                  Specify advanced parameters for kernel 
                                        compilation
  --advanced.prop arg                   Specify advanced kernel or solution 
                                        properties for kernel compilation

[vivado] section:
  --vivado.impl.jobs arg                Set the number of jobs for launching 
                                        VPL implementation runs
  --vivado.impl.lsf arg                 Specify a bsub command to submit a job 
                                        to LSF for VPL implementation runs
  --vivado.impl.strategies arg          Specify comma-separated strategy names 
                                        for VPL implementation runs, use 
                                        keyword 'ALL' if all available 
                                        strategies are desired
  --vivado.param arg                    Specify advanced Vivado parameters for 
                                        kernel compilation
  --vivado.prop arg                     Specify advanced Vivado properties for 
                                        kernel compilation
  --vivado.synth.jobs arg               Set the number of jobs for launching 
                                        VPL synthesis runs
  --vivado.synth.lsf arg                Specify a bsub command to submit a job 
                                        to LSF for VPL synthesis runs

[linkhook] section:
  --linkhook.custom arg                 <step name, path to script file> 
                                        Specify a script to execute at a 
                                        factory predefined point in an internal
                                        step.
  --linkhook.do_first arg               <step name, path to script file> 
                                        Specify a script to execute as a 
                                        precondition to the given step name. 
                                        Value is an absolute path or partial 
                                        path relative to the build directory.
  --linkhook.do_last arg                <step name, path to script file> 
                                        Specify a script to execute immediately
                                        after the given step completes. Value 
                                        is an absolute path or partial path 
                                        relative to the build directory.
  --linkhook.list_steps                 List run steps that support script 
                                        hooks for a given target (use with 
                                        --target). Also lists custom factory 
                                        defined hooks by name.

[package] section:
  --package.aie_debug_port arg          TCP port where emulator will listen for
                                        incoming connections from the debugger 
                                        to debug AIE cores. Valid if used with 
                                        AIE Compiler archive file (libadf.a) as
                                        input file, targeting hw_emu and Versal
                                        platform
  --package.bl31_elf arg                Specify absolute or relative path to 
                                        ARM trusted FW ELF that will execute on
                                        A72 #0 core. Valid for a Versal or Zynq
                                        UltraScale+ Embedded (Edge) platform
  --package.boot_mode arg               <ospi|qspi|sd> Boot mode used for 
                                        running design on emulator or hardware.
                                        opsi: valid for Versal DataCenter 
                                        platform
                                        sd: valid for Embedded (Edge) platform
                                        qspi: valid for Versal Embedded (Edge) 
                                        platform or a hw/hw_emu target and 
                                        Zynq/Zynq UltraScale+ platform
  --package.defer_aie_run               The AIE cores will be enabled by PS 
                                        application. When unset, generate CDO 
                                        commands to enable AIE cores during PDI
                                        load instead. Valid if used with AIE 
                                        Compiler archive file (libadf.a) as 
                                        input file and Versal platform
  --package.domain arg                  Specify a domain name
  --package.dtb arg                     Specify absolute or relative path to 
                                        DTB used for loading Linux on APU. 
                                        Valid for Embedded (Edge) platform
  --package.emu_ps arg                  <x86|qemu> Specify if PS code is 
                                        compiled for x86 or ARM. Default value 
                                        is x86. Valid for sw_emu target and 
                                        Embedded (Edge) platform
  --package.enable_aie_debug            Generate CDO commands to stop AIE cores
                                        during PDI load.
  --package.image_format arg            <ext4|fat32> Specify output image file 
                                        format. EXT4 not available on Windows. 
                                        Valid if boot mode is sd
  --package.kernel_image arg            Specify absolute or relative path to a 
                                        Linux kernel image file. Overrides 
                                        existing image available in the 
                                        platform. Valid for Embedded (Edge) 
                                        platform
  --package.no_image                    Bypass sd_card image creation. Valid if
                                        package.boot_mode is sd
  --package.out_dir arg                 Specify absolute or relative path to 
                                        output directory of package flow
  --package.ps_debug_port arg           TCP port where emulator will listen for
                                        incoming connections from the debugger 
                                        to debug PS cores. Valid for hw_emu 
                                        target and Embedded (Edge) platform
  --package.ps_elf arg                  <ps.elf,core> For example 
                                        a72_0.elf,a72-0. Valid for Embedded 
                                        (Edge) platform
  --package.rootfs arg                  Specify absolute or relative path to a 
                                        Linux root filesystem file with ext4 
                                        extension. Valid for Embedded (Edge) 
                                        platform
  --package.sd_dir arg                  A directory path to package into the 
                                        sd_card directory/image. Valid if boot 
                                        mode is sd
  --package.sd_file arg                 ELF or other data file to package into 
                                        the sd_card directory/image. Valid if 
                                        boot mode is sd
  --package.uboot arg                   Specify a path to U-boot ELF file which
                                        overrides a platform U-boot. Valid for 
                                        Embedded (Edge) platform

[profile] section:
  --profile.aie arg                     <ADF graph argument|pin name|all>
                                        Enable profiling AIE streams
  --profile.data arg                    <[kernel_name|all]:[compute_unit_name|a
                                        ll]:[interface_name|all](:[counters|all
                                        ])>
                                        Enable profiling kernel data transfers
  --profile.exec arg                    <[kernel_name|all]:[compute_unit_name|a
                                        ll](:[counters|all])>
                                        Enable profiling kernel execution
  --profile.stall arg                   <[kernel_name|all]:[compute_unit_name|a
                                        ll](:[counters|all])>
                                        Enable profiling kernel stall
  --profile.trace_memory arg            <FIFO:<size>|<MEMORY>[<n>]|<MEMORY[<n>]
                                        :SLR<m>. Specify trace buffer memory 
                                        type for profiling. FIFO size is 
                                        specified in KB. Used when profiling is
                                        enabled during hw target linking. 
                                        Default is either the first memory 
                                        available or FIFO:8K. SLR<m> can be 
                                        specified only with DDR or HBM types

Deprecated options:
  --dk                          Standardization: The preferred alternative is 
                                'debug.chipscope','debug.list_ports', 
                                'debug.protocol. 
  --hls.max_memory_ports        Replaced by alternative option: 'hls.pre_tcl'. 
                                Create a TCL file with a vitis_hls TCL command 
                                'config_interface -m_axi_auto_max_ports=1'. 
                                Specify the TCL file using '--hls.pre_tcl'.
  --hls.memory_port_data_width  Replaced by alternative option: 'hls.pre_tcl'. 
                                Create a TCL file with vitis_hls TCL commands 
                                'config_interface -m_axi_min_bitwidth <width>' 
                                and 'config_interface -m_axi_max_bitwidth 
                                <width>'. Specify the TCL file using 
                                '--hls.pre_tcl'.
  --jobs                        To ensure input line works for supported 
                                operating systems or shells, command line usage
                                is deprecated. The alternative is to specify 
                                options 'hls.jobs', 'vivado.synth.jobs' in a 
                                configuration file. 
  --lsf                         To ensure input line works for supported 
                                operating systems or shells, command line usage
                                is deprecated. The alternative is to specify 
                                options 'hls.lsf', 'vivado.synth.lsf' in a 
                                configuration file. 
  --package.ps_on_x86           Replaced by alternative option: package.emu_ps.
                                New option takes either 'x86' or 'qemu' as a 
                                valid value. If not specified, 'x86' will be 
                                set by default
  --profile_kernel              Replaced by alternative option: 'profile.*'. 
                                New options extend profiling beyond kernel and 
                                compute units to include additional interfaces.
  --trace_memory                Replaced by alternative option: 
                                'profile.trace_memory'. New options extend 
                                profiling beyond kernel and compute units to 
                                include additional interfaces.
