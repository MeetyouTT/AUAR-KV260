## 实际设备与网络

沙箱内未显示串口，主机侧只读检查找到了 Xilinx 四串口。沿用已审阅的 UART 传输与独占/完整性检查，实际连接成功。初始 `ls` 返回 2 的原因是不存在 `/dev/ttyACM0`，不影响已经找到的 Xilinx USB 串口。

实测 KV260 boot 为 `87de5501-540e-4799-9285-2d7048c1ae90`，PetaLinux 2022.2；MCP01 和 Webcam 均有录音接口。MCP01 原生输入是 S16_LE/16000/mono，输出是 S16_LE/48000/stereo。麦克风开关为 on，本轮没有改增益/静音/音量。

`eth0` 为 UP/NO-CARRIER、无 IP，路由表为空，因此不能经 LAN 连接 Windows。已通过异步问题请用户接同一局域网并提供 Windows IP/服务状态；本轮没有擅自设置 IP、改路由或把互联网接入当作必需。

## 已解决的助手问题

- 首次完整验收脚本超过已有 UART 行长度预检，命令未发送；随后采用分段上传并检查源码 SHA，实际验收通过。该预检失败不影响板端已有服务。
