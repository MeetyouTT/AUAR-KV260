# J2 五秒 PWM 测试

用户要求连续约 5 秒输出：50 Hz、1500 µs 高电平、250 帧，结束后回到低电平。独立目录继承一秒版本的接口与接线约定，保留原工程及历史证据。五秒版本使用独立固件目录 `aura-pwm-probe-5s` 和固件名 `aura_pwm_probe_5s.bit.bin`，不是重复触发五次一秒波形。

当前在准备构建，尚未加载或发送五秒 PWM。舵机保持拔下，仅进行数字信号测量。PL 测试配置暂时替代官方 DPU；测试结束可恢复原官方应用。

输入端示波器：CH1 VIB/GND1，本体与软件 10×，DC 1 MΩ、1 V/div、5 ms/div、CH1 上升沿、触发约 1.6 V。观察完整五秒范围可改为 500 ms/div 或 1 s/div；测脉宽时用 5 ms/div。不同侧测量要同时移走并重接探头尖和地夹，避免跨接 GND1/GND2。
