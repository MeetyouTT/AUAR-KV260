# DPU＋motion 资源适配候选

本目录用于检验现有 B4096 工程能否放入真实控制逻辑，不是正式 motion release。候选只有一个输出轴，`J2.3/E10`；不改板端当前 PL，不启动舵机。通过联合实现也不能代替重新生成 XSA/HWH、冻结 ABI、板级 DPU＋PWM 同启动测试及机构标定。

源设计为 `kv260-m3-axilite-20261002` 的最终 routed DCP；保留 DPU、显示及主体参考平台，用新控制模块替换 M3 AXI 寄存器叶节点。使用独立输出目录，不修改源 DCP。

完整旧平台联合候选已经被 placer 的高利用率检查拒绝。当前增加 `USB_AUDIO_NO_PL_I2S` 容量 profile：旧音频 SS 替换为 3 个返回 DECERR 的控制端点，所有旧音频 DMA 请求和 IRQ 静默，VCU 共享互连保留。原始 routed 检查点的跨层 buffer/inverter alias 必须逐一保留并核对极性，不能删除后任意填 0。此 profile 的真实联合结果以 verification JSON 为准；正式平台需删除对应旧设备树节点，未部署到板端。

实际导入揭示了另一个硬冲突：源设计的 E10 被 `lrclk_tx` 占用。当前方案采用 USB 音频，候选断开旧 I2S TX 时钟到该 pad 的连接，复用原 OBUF 输出 PWM；容量试验中的外部端口暂保留旧名 `lrclk_tx`，`io_binding.txt` 记录新作用。正式 release 必须在 BD/XDC 明确移除冲突并导出 `servo_pwm`、更新硬件描述，不能把旧 HWH 或设备树当成已匹配。此处停用旧 I2S TX 时钟，不能同时使用该旧音频链。

候选 ABI ID `MFIT`、版本 1、地址沿用 M3 的 `0x80080000`；这是资源试验的地址，并不冻结最终运动 ABI。单位为名义微秒，不是正式毫度接口。

| offset | 内容 |
| --- | --- |
| 0x00 / 0x04 / 0x08 | ID / 候选 ABI / build marker |
| 0x0c | reason[7:4]、bound[3]、referenced[2]、armed[1]、active[0] |
| 0x10 / 0x14 / 0x18 | 影子 session / epoch / seq |
| 0x1c / 0x20 | 影子目标脉宽 / 有限租约 ms |
| 0x24 | 命令；完整 WSTRB=0xf |
| 0x28 / 0x2c / 0x30 | accepted seq / 有效脉宽 / 剩余租约 |
| 0x34 / 0x38 | 已绑定 session / epoch |

命令值见 RTL 的 `BIND / REFERENCE / ARM / COMMIT / STOP` 常量。允许的脉宽为 1400—1600 名义 us，中心 1500、每 20 ms 帧最多改变 4 us，租约 1—500 ms。影子寄存器完整写入后显式 COMMIT；范围、权限、session/epoch、严格递增 seq 不合法则拒绝，重复提交不能续租。STOP 或到期清除许可、输出拉低，再通信不自动启动；复位默认禁能。参考确认是软件操作，本候选没有位置传感器。

参考硬件描述给出的控制时钟为 99.999001 MHz，分频使能为 100；据此推导，名义 us 约为 1.00000999 us（约 10 ppm）。该差值是硬件描述的计算结果，不是本候选的板上频率测量；正式部署仍须复核实际周期与脉宽。运行中不做通用除法/乘法、不派生新时钟。正常脉宽在帧边界更新，停止优先截断。候选未加入最终毫度标定映射、双轴、物理急停输入和六态完整监督，不能用这个资源数代表最终版本的全部资源。

本容量候选的 PWM 使用组合比较输出，尚未验证门级短脉冲；正式 release 应改为寄存器输出，并重新进行时序与板端脉冲完整性验收。本候选不用于当前机械动作。

PWM 接收端异步，约束给时钟寄存器到 pad 的 100 ns max-delay 工程预算；不伪造外部同步采样时钟。原平台 MIPI/I2C/其余 I2S 的约束缺口必须单独披露，禁止用全局 false-path 掩盖。

仿真检查 AW/W 不同到达顺序、未授权/未确认参考的拒绝、20 ms 等比例周期、变化率、重复序号、范围、会话/代次、冻结写方后的到期、STOP、复位及非法/部分写入。
