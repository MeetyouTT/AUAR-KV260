## 实现与待验证的区别

已实现：标准库模拟入口、CPU 参考适配、IoU 跟踪接入、可选 ByteTrack 适配、SQLite 身份库、候选时效策略、单任务调度、目标与说话人结果门、异步主机和两条会话合同、虚拟监督、日志、源包校验、既有 FSM/UI 状态接入。

当前系统 Python 为 3.8.10；缺 OpenCV/NumPy、PySide6、pytest/jsonschema 等可选依赖。已有 `.venv` 或 Windows 模型环境没有被修改，真实设备及大模型环境没有被探测或安装。

本次未执行相机录制、CPU/DPU 实图推理、真实 ASR/VLM/TTS、跨机器媒体传输、MCP01、Qt 窗口、舵机动作或新 FPGA 构建/加载。ByteTrack 和 Light-ASD 尚未实际运行；项目 DPU 检测/身份模型仍待交付。历史独立实验的板测进度仍以各原报告为准，不能由本次软件通过替代。

原 RTL 只支持相对租约，新的 PL 绝对源期限监督未实现。虚拟监督依赖软件轮询，不能证明 PS 失效时独立关输出。误差界、可变期限和任务成本参数尚未用独立数据标定；G0–G5 是实验配置计划，六组板端实验未执行。

机构继续等待 3D 模型，物理运动保持禁用。下一项具体开发是按 [项目框架的接入顺序](PROJECT_FRAMEWORK.md) 固定项目检测模型与 DPU 适配，再接跟踪、身份和真实媒体链。

## 源包

`scripts/package_project.py` 生成带每文件 SHA256 的框架源包，并提供独立校验入口。默认包含 CPU 参考权重，排除大型动画素材、个人数据库、原始媒体、环境、设备平台工件和历史相邻交付目录。源包实际生成/迁移检查保存在 `metrics/raw/framework-validation-20261009/package_validation.json`；该记录留在源仓，默认源包不携带本机日志。
