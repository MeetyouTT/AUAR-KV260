- 当前 RTL 仅支持 START/STOP，脉宽是构建参数，0x028 为只读。重启同一份 1.5 ms PWM 不改变目标位置；已在目标位置时可能没有可见动作。软件脉宽扫描未实施。

## 本次应使用的连接

| 信号或供电 | 连接 |
|---|---|
| KV260 PWM | **J2.3 → 模块 VIB**（替代旧图 J2.1） |
| KV260 3.3 V | J2.11/12 → VDD1 |
| KV260 GND | J2.9/10 → GND1 |
| 舵机侧 5 V | SVPDB-8S Vx → VDD2，且舵机红线接 Vx |
| 舵机侧 GND | SVPDB-8S G → GND2，且舵机负极接 G |
| 隔离后 PWM | VOB → SVPDB-8S 单排信号1 → 同列输出 S → 舵机信号 |

供电板“信号1”是供电板的通道编号，与 KV260 的 J2.1 无关。模块端子依实物丝印辨认；不把芯片封装脚号当成模块排针位置。

按这份隔离方案 GND1 与 GND2 不跨接，各侧信号参照本侧地。此前直接接舵机时的共地说明不适用于本次隔离接法，实际是否跨接尚未核验。

## 下一步实测

先核对 VIB 是否实际接 J2.3。若需换线，先断开舵机侧动力电源，再改接。

确认后测隔离输出：单通道探头尖接 VOB，地夹接 GND2/SVPDB-8S G；移除输入侧的示波器接地夹和其他通道探头，避免仪器把两侧地跨接。CH1 直流，探头与通道均10×，2 V/div、5 ms/div、上升沿触发约2.5 V。

在 VDD2 实测约5 V的条件下，预期输出平台约0/5 V、周期20 ms、高宽1.5 ms。再在舵机插口 S/G 测同样波形，并确认红线对负极在连接舵机时约5 V。VOB 正常而插口没有波形时，查供电板信号通道或接线；VIB 正常、VOB 不正常时，查模块方向和两侧供电。

理想平均电压按占空比计算：3.3 V输入侧约0.2475 V，5 V输出侧约0.375 V。因此隔离后万用表读约0.36 V可以是正常平均值，不能据此判断高电平只有0.36 V。若示波器的高平台本身仅数百mV，则不符合该预期，仍需定位。

只有确认舵机端供电和波形后，才用改变脉宽的小角度测试区分“已到目标”与“不能动作”；当前未做此测试，不能判定舵机或FPGA损坏。
