# KV260 当前界面录音复验

2026-10-16，用户要求“先测试下能否录音”。本轮直接在当前已部署的双层GTK界面操作，并另取同一MCP01设备的5秒PCM做信号检查。

## 实际结果

- 原生GTK/XTest点击“开始录音 / 停止录音”，取得62000样本、3.875秒、124000字节PCM的结果；再次开始并点击取消后，结果为空、可重新开始。
- 另一次独立MCP01采集准确取得80000样本 / 5秒，16kHz、单声道、S16_LE。保存的WAV为160044字节。
- 独立重算信号：峰值18987，RMS1916.698（约-24.66dBFS），79732个非零样本，削波样本0。因此本轮确认设备能够实际采集非静音音频；未据此声称特定语句可识别或人声清晰度已验收。
- 最终在玩偶交流页 / 演示层，界面录音已取消、无保留结果、可重新录音；音量58%、非静音、全屏保持。独立采集进程已结束。
- 相机PID984和代次保持；同轮采集+154帧、检测+122帧。没有重启服务、更新系统或运行识别模型。
