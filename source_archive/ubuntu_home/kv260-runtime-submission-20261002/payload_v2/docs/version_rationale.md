## 不能混淆的两条硬件记录

原 `kria-vitis-platforms` 的 `xlnx_rel_v2022.2` 固定为 `a3a83f179503792226adf83082aee7c05de620b4`。原样参考 benchmark 使用 DPU 4.0，架构指纹 `0x101000016010407`；已成功构建，但这不与原板镜像、原 XMODEL 自动等价。

后续独立 DPU 4.1 兼容工程和 M3 使用 AMD DPU 4.1 TRD 依赖，匹配原板及原 ResNet18 的 `0x101000056010407`。SAVE Argmax 对应真实硬件配置差异，不能仅编辑 arch.json 或跳过 VART 检查解决。本运行时附件不改变任何 DPU IP、位流、架构指纹或模型。

当前有限板测基线为 1 CU、B4096、300 MHz、控制地址 `0xa0010000`；M3 是 DPU 加最小 AXI-Lite 寄存器，尚无 PWM。不要把早期 DPU 4.0 工件当作本附件的新硬件成果或直接部署目标。

正式参赛总报告仍须合并完整硬件/应用版本、实现报告和源码入口；本附件只完成运行时部分说明。原始硬件来源和既有 DRC/时序问题以各阶段封存报告为准。
